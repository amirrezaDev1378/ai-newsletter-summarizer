Building a computer that can pause and resume in milliseconds: Inside the MicroVM architecture behind Managed Agents (20 minute read)

Opinions & Advice

How to Measure the Human Cost of Agent Work (8 minute read)

Measure agent workflows by the human effort and agent spend required to reach an accepted result, including time spent briefing, supervising, reviewing, correcting, and verifying the work. Keep failed attempts and manual rescues in the totals so successful tasks do not hide the cost of unsuccessful ones. Track quality and later defects alongside time, and compare similar tasks under the same acceptance criteria before claiming productivity gains.
What I Self-Host (15 minute read)

A home server runs 28 services, including Jellyfin, Immich, Home Assistant, and Vaultwarden, on a mini PC with 16 GB of RAM. The setup favors simple native services and systemd-managed Podman containers, keeps services behind a VPN, and rejects tools whose operational complexity outweighs their value.
Code Is a Commodity Now (11 minute read)

Cheaper code generation could push software agencies away from selling development hours and toward domain expertise, product judgment, and accountability for outcomes. The essay argues that smaller generalist teams and changing hiring signals follow from this shift, while acknowledging mixed productivity evidence and the cost of verifying changes in mature codebases.

Vector search can't tell which memory is current (Sponsor)

Plain vector retrieval returns the old preference and the new one, and passing stale context to an LLM leads to hallucinations and conflicting actions. Graph-aware retrieval fixes this at the database layer with typed edges linking each memory to the one it replaced, and lifecycle flags marking what's active. The agent gets a clean current state, and the full history stays intact.

Meta has released Muse Spark Open, a multimodal model with 816 billion total parameters, 42 billion active parameters, and a one-million-token context window. It supports coding and agentic workflows through hosted APIs or local inference, including on two M5 Ultra Mac Studios, with weights available under a license that includes limited commercial terms.
