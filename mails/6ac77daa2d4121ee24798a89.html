Articles & Tutorials

A Hitchhiker's Guide to Postgres Text Search (14 minute read)

Cortex replaced a Lucene-based search architecture with PostgreSQL full-text search, a custom query parser, weighted ranking, and CDC-fed indexes. The change cut public API p95 latency from 13.3 seconds to 1.54 seconds, reduced total memory use by about 40%, and made most edits searchable within seconds.
A Token Is Not a Message: Stop Storing AI Responses Like Event Logs (21 minute read)

Streaming tokens as event logs makes refreshed or late-joining clients rebuild partial responses, while rewriting one record for every token overloads the database. The article compares four storage patterns and argues that message appends can return the full response so far, continue live delivery, and save only the completed message to application storage.
