News & Trends

Kubernetes v1.37: Tracking When a PersistentVolumeClaim Was Last Used (Beta) (3 minute read)

Kubernetes v1.37 promotes the PersistentVolumeClaimUnusedSinceTime feature gate to Beta, enabling it by default. The PVC protection controller adds an Unused condition to each PersistentVolumeClaim to indicate whether a running pod references it. This eliminates the need for custom tooling to identify orphaned storage. Administrators can use the condition's timestamp to find PVCs that have been idle for specific periods.
Python Workers are now generally available (8 minute read)

Python Workers are now generally available on the Cloudflare Developer Platform. The runtime natively supports Cloudflare bindings, so developers can connect to services like R2 and D1 without writing JavaScript code. Users can also run frameworks like FastAPI, Django, and Flask or integrate AI libraries like langchain and openai.
Prometheus and OpenTelemetry interoperability in 2026 - Survey results (5 minute read)

Cutting CI pipeline time by 64%: What actually works in production (6 minute read)

An engineering team reduced their Merge Train pipeline duration from one hour to 22 minutes, a 64% reduction. They achieved this while growing their test suite by 90% and improving CI health from 82% to above 90%. Infrastructure costs rose roughly 10%, but the team estimates they regained over 1,300 engineer hours previously lost to delays and retries. Key changes included upgrading to Intel hardware and separating service tests from browser-based tests.
What Sun got wrong (6 minute read)

Sun Microsystems paired strong technology and strategy with weak operational execution, including basic failures in sales and customer responsiveness. A 2005 startup running OpenSolaris tried to buy Sun hardware but struggled to get a response, while Dell quickly handled pricing, financing, and delivery—an example of how neglecting the mechanics of running the business can erase technical advantages.
Markdown in /src (6 minute read)

Markdown can serve as the durable source of intent for agent-generated software, capturing architectural, data, API, and implementation decisions that would otherwise disappear in ephemeral prompt sessions. Keeping that Markdown alongside code in /src makes it diffable, reviewable, and available to both humans and agents, while tests can be derived from it to verify the resulting implementation.
