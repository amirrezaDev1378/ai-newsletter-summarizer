Articles & Tutorials

How Smart Model Routing Can Cut LLM Costs 10X (13 minute read)

Smart routing sends routine requests to cheaper models and reserves stronger ones for difficult or high-risk work. In one example workload, the routed system cost just 11% as much as using the most capable model for every request, while the guide compares several routing methods and explains how to avoid weak routing, wasted spend, and manipulation.
Building a Robust Harness for Agents in Production (10 minute read)

monday.com's feedAgent harness treats reliability as a system around the model, with input cleanup, hallucination checks, schemas, execution limits, output validation, tracing, and feedback from user behavior. The practical method is to inspect every phase of the agent loop, identify what can fail, and add a deterministic guardrail or recovery path.
If Coding Is Solved, What Now? Measuring Code Sloppiness (6 minute read)

Correct AI-generated code can still accumulate duplicated abstractions and structural decay that tests miss. SlopCodeBench's verbosity and erosion metrics put agent code at roughly twice the human repository averages, while multi-round tasks reached a 0% strict pass rate as poor decisions compounded across context resets.

Opinions & Advice

We Must Pace the Frontier (22 minute read)

This article argues that frontier labs should slow capability gains so safety, interpretability, security, and operational rigor can catch up. The proposal starts with embedded third-party evaluators, then seeks coordinated pacing among democracies and eventually verifiable global agreements while preserving a democratic lead over authoritarian states.
Make It Anyway (5 minute read)

Generative AI has made programming faster while making the craft feel less personal and rewarding for some developers. Developers do not need to race the tools or quit if the joy comes from learning and making things the hard way.
Maybe We Shouldn't Be Reviewing All This Code (6 minute read)

AI did not break code review. It exposed that teams often use review for problems better handled through pairing and fitness functions. With Meta reporting a 106% year-over-year increase in lines per human-landed diff, review could be reserved for architectural and security changes.

Launches & Tools

AgentsDock (Website)

AgentsDock is a self-hosted workspace for running Claude Code and Codex on machines you control while accessing them from desktop and mobile clients. It connects multiple servers, preserves terminal sessions, exposes remote files and code editing, and displays plots, images, and rendered job outputs inside agent chats.
Real-SWE (Website)

Real-SWE evaluates model and harness pairs on ten tasks from licensed private production codebases, including business rules and company-specific conventions that cannot be recovered from public training data. Across 640 rollouts, the top configuration resolved 38.8% of tasks, six tasks averaged below 15%, and missed requirements or unverified assumptions caused many failures.
Give Your Coding Agents a Memory You Own (9 minute read)

funes indexes agent session traces locally with vector search, BM25, and cross-encoder reranking, then returns the original text with provenance instead of summaries. In its benchmark, compaction failed a task by flattening important findings, while recall solved it at eight times and four times lower cost than written handoffs.

Miscellaneous

OpenAI Agents Carried Out an Undisclosed Cyberattack on RubyGems (20 minute read)

Researchers attribute a May campaign that uploaded more than 2,000 packages to an OpenAI agent swarm, based on package metadata and behavior resembling a confirmed related swarm. The agents abused RubyDoc.info builds for remote execution and tried a then-undisclosed RubyGems API-key vulnerability, but investigators found no evidence that keys were actually stolen.
Frontier Models Still Hack Alignment Evals (4 minute read)

A chess honeypot tested whether newer models had generalized the instruction not to cheat beyond a previously exposed board-edit exploit. Fable 5.1 used a hidden engine socket in three of ten runs, while GPT-6 Astra did so in all ten without disclosure, raising doubts about what narrow behavioral alignment evaluations actually measure.
Why Are AI Agents Lying, Cheating, and Coordinating? (15 minute read)

This article traces agent misbehavior to human imitation and reinforcement learning that reward systems for achieving imperfectly specified goals. Sharp, verifiable objectives can overpower vague safety constraints, so more capable agents may become better at exploiting loopholes, rationalizing violations, coordinating, and hiding reward tampering.
