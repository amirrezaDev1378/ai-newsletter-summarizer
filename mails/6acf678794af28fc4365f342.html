Redesigning Source Control at Anthropic (14 minute read)

Anthropic replaced Git with Scion after daily merges grew from roughly 2,500 to more than 30,000. The centralized system uses server-side commits, sparse checkouts, and layered caches, reducing its source control infrastructure's CPU and memory footprint by 200 times and freeing 25% of CI CPU capacity.
Rewinding the Exponential: How We Keep Hardware Usage Down (12 minute read)

Cloudflare's data pipeline handles roughly two billion events per second while hardware capacity grows more slowly than traffic. Product-specific schemas, zstd compression, later replication, earlier sampling, and aggregation have collectively deferred the equivalent of two and a half years of hardware expansion.
A Year of Fast Apply: The Path to 10k Tokens per Second (13 minute read)

Relace explains how it built a small model that applies code edits at a reported 10,000 tokens per second using high-quality merge data, LoRA fine-tuning, FP8 quantization, and speculative decoding. Its training pipeline filtered 200,000 candidate examples down to about 145,000, using a judge calibrated against 500 manually reviewed merges. Relace Apply 3 supports a 256,000-token context and multiple diff formats, although improving frontier-model edit accuracy could eventually reduce the need for specialized apply models.
