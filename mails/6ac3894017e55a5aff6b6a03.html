Introducing Cloudflare Traces: follow requests through our entire platform (5 minute read)

Cloudflare Traces is now available in open beta, extending automatic tracing beyond Workers to the rest of the request path. Users can view security rules, transformations, cache decisions, and origin handling in one trace without special configuration or plugins. The feature supports OpenTelemetry and enables users to control sampling rates or trace 100% of specific traffic using Trace Rules.

Opinions & Tutorials

Closed-loop incident response: connect AWS DevOps Agent to OpenSearch (9 minute read)

A new AWS guide explains how to connect AWS DevOps Agent to Amazon OpenSearch Service using the Model Context Protocol (MCP). This setup allows an AI agent to automatically investigate alerts by querying logs and traces, rather than requiring manual intervention from an engineer. Organizations can host the MCP server on Amazon ECS, Amazon Bedrock AgentCore, or use the built-in endpoint on OpenSearch version 3.3+.
Halving the Time: How Uber Eats Rebuilt Its Search Pipeline (8 minute read)

Uber cut end-to-end Eats search latency in half by removing low-value retrieval paths, separating ranking features from presentation data, and eliminating false dependencies between pipeline stages. Additional gains came from pagination, concurrent rendering, request hedging, compact embeddings, and fixing service-mesh connection bottlenecks.

Resources & Tools

Agents multiply PRs. Brex cut per-change preview costs up to 99%. (Sponsor)

Duplicating namespaces for every change doesn't scale when engineers and coding agents are both shipping. Brex moved to Signadot's lightweight ephemeral environments on a shared cluster, cutting preview infrastructure costs by 99% and preview time 80%. See how they scaled testing across hundreds of engineers and agents.
Impeccable (GitHub Repo)

Impeccable is a design skill for AI coding agents that includes 24 commands and 61 deterministic detector rules for identifying common problems in AI-generated frontend design. The tool works with editors including Cursor, Claude Code, VS Code, and Grok Build.
T3code (GitHub Repo)

T3 Code is an "agent harness control surface" that manages AI agents from Claude, Codex, Cursor, and other platforms. Users can control these agents through mobile, web, and desktop apps.
Rebalancer (GitHub Repo)

Meta open-sourced Rebalancer, a library for assigning tasks, shards, servers, and traffic while balancing resource limits, placement constraints, and optimization objectives. It supports local-search and mixed-integer solvers, plus a Dockerized Explorer interface for debugging why assignments were made and which constraints are binding.
