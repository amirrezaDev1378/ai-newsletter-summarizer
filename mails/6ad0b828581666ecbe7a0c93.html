Lazy Loading Images and Media: How Far Ahead Browsers Fetch (6 minute read)

Browsers fetch lazy-loaded media at different distances, with Chrome adjusting its margin based on connection speed, Firefox using a fixed 600-pixel threshold, and Safari applying a viewport-based threshold to images. The article explains why the largest contentful paint image should load eagerly and why media dimensions should be reserved to prevent layout shifts. Its practical takeaway is to use native lazy loading selectively, based on how far ahead each browser fetches.
From 2,500 requests to 24: Rebuilding star history without the stargazers (7 minute read)

GitHub rebuilt its star-history API to return up to 30 weeks of daily counts in one request. Maintainers can track a project's momentum without exposing stargazer identities, which could be scraped for spam or phishing. To avoid simply shifting the cost to count queries, the endpoint filters stars by time before counting, reducing database work.
