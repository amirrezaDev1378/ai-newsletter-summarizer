News & Trends

Building a post-quantum certificate authority with Merkle Tree Certificates (10 minute read)

Cloudflare is launching a certificate authority that will support Merkle Tree Certificates (MTCs), targeting early 2027 for inclusion in Chrome's Quantum-resistant Root Store. The company will provide standard MTC issuance at no cost. MTCs batch certificates into an append-only Merkle tree to address the scaling issues of post-quantum cryptography, which can increase log storage requirements by 40 times. Cloudflare successfully tested the technology with Chrome, serving billions of MTCs and finding that median performance was 9% faster than classical signature chains.
Amazon S3 Vectors now supports metadata pre-filtering for higher recall on filtered searches (5 minute read)

AWS has introduced metadata pre-filtering for Amazon S3 Vectors to improve recall on filtered queries. The feature evaluates metadata filters before running a similarity search and supports up to 100 filter constraints per query. On highly selective filters, pre-filtering returns up to five times more matching vectors than previous methods. It is available immediately at no additional cost and works on existing indexes without requiring data re-ingestion.
Cloudflare Containers, rebuilt to scale agent sandboxes (15 minute read)

Cloudflare has rearchitected its Containers service to handle agent workloads, allowing code to select the image and instance type at runtime. The update introduces a new scheduling policy that starts containers six times faster, with median startup times falling from over four seconds to 648 milliseconds in independent benchmarks. A filesystem snapshots feature is also available in public beta to let workspaces save and restore their state.
