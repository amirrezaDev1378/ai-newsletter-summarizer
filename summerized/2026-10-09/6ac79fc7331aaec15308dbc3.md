### [Multimodal embeddings beyond a single vector (17 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fwww.perplexity.ai%2Fhub%2Fblog%2Fmultimodal-embeddings-beyond-a-single-vector%3Futm_source=tldrai/1/010001a11bc816f5-bc70919d-ea6a-47bb-9055-109bbadd083a-000000/LSqiIPhZe-I3ramayUP1jX0wn02Leerx6RgaAjQlM7o=452)
The Perplexity team launched PPLX-EMBED-V2-LATE, providing multi-vector, multimodal embeddings that enable richer retrieval across text and images. These models retain token-level vectors and utilize a shared embedding space, leading to improved retrieval on benchmarks like ViDoRe(V3). Available in two sizes, 0.6B and 9B, they offer industry-leading performance for various retrieval tasks while maintaining efficiency.

### [Introducing OpenDocRouter: every document model under one API (5 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fwww.llamaindex.ai%2Fblog%2Fintroducing-opendocrouter%3Futm_source=tldrai/1/010001a11bc816f5-bc70919d-ea6a-47bb-9055-109bbadd083a-000000/hJ-YhdM3qG80jbzdrKb9ScLc-SGWlsl7VKN1kKil010=452)

The API accepts PDFs, PNG, JPEG, or URLs to those file formats. Users can toggle between synchronous responses, where the result is returned directly, and asynchronous responses, where a job is created that requires polling.
