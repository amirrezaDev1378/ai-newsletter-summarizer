## Articles & Tutorials

### [A Hitchhiker's Guide to Postgres Text Search (14 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fbuilders.cortex.io%2Fblog%2Fa-hitchhikers-guide-to-postgres-text-search%2F%3Futm_source=tldrdev/1/010001a11b42d0e8-47fd7f13-faf8-4f1c-ab84-8bfbe63867c8-000000/RBGCArYgY7AjyJOAcrDUyZlYlniQ1OfqOjf3AMqDe74=452)
Cortex replaced a Lucene-based search architecture with PostgreSQL full-text search, a custom query parser, weighted ranking, and CDC-fed indexes. The change cut public API p95 latency from 13.3 seconds to 1.54 seconds, reduced total memory use by about 40%, and made most edits searchable within seconds.

### [A Token Is Not a Message: Stop Storing AI Responses Like Event Logs (21 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fably.com%2Fblog%2Fstore-streamed-ai-responses%3Futm_source=tldrdev/1/010001a11b42d0e8-47fd7f13-faf8-4f1c-ab84-8bfbe63867c8-000000/iyKPKxfjcvIUlrOX5p_aLhRK5vl0rl5AzX9IOOS-qOY=452)
Streaming tokens as event logs makes refreshed or late-joining clients rebuild partial responses, while rewriting one record for every token overloads the database. The article compares four storage patterns and argues that message appends can return the full response so far, continue live delivery, and save only the completed message to application storage.

## Opinions & Advice

### [Anti-Patterns in Software Blogging (10 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Frefactoringenglish.com%2Fblog%2Fanti-patterns-software-blogging%2F%3Futm_source=tldrdev/1/010001a11b42d0e8-47fd7f13-faf8-4f1c-ab84-8bfbe63867c8-000000/HxBaoUxh1zQtGzwpaOsqWHAOS15WwfJGXWavaUnIPKU=452)
Software blogs lose readers when they meander, assume too much background knowledge, or outsource key explanations to links. The guide recommends stating the payoff in the title and opening sentences, writing for a specific reader, and keeping external references optional.

### [JPEG XL Finally Lands in Chrome! (3 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Ftonisagrista.com%2Fblog%2F2026%2Fchrome-jpegxl%2F%3Futm_source=tldrdev/1/010001a11b42d0e8-47fd7f13-faf8-4f1c-ab84-8bfbe63867c8-000000/JUGTxqYyuP81fT1duyycy7Bmn-ApO9TgZHTVcQWsxho=452)
Chrome 155 will ship a memory-safe JPEG XL decoder built in Rust, reversing the browser's earlier decision to remove support. Chrome's reach could make the format mainstream, especially for high-fidelity photography, lossless compression, progressive decoding, and lossless JPEG transcoding.

### [Reasons to Dislike AI Coding (3 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fwww.sicpers.info%2F2026%2F10%2Freasons-to-dislike-ai-coding%2F%3Futm_source=tldrdev/1/010001a11b42d0e8-47fd7f13-faf8-4f1c-ab84-8bfbe63867c8-000000/abT1D9Aehdd7CLQWiPAnAe8x3GQ77NitonVJUot_dt4=452)
The essay examines five objections to AI coding: code as art, job displacement, dehumanizing work, rule-based views of software engineering, and support for powerful AI companies. It argues that several critiques depend on debatable assumptions about what software work is for, while locating the strongest human concern in labor relations and control of production.

## Miscellaneous

### [The Agentic Development Loop (5 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fhaydenbleasel.com%2Fwriting%2Fultracite%3Futm_source=tldrdev/1/010001a11b42d0e8-47fd7f13-faf8-4f1c-ab84-8bfbe63867c8-000000/Snos31aqR7mOegVGXIeZhVF7j9Smxgkkdbn--Sd6xaQ=452)
Agentic development changes the ideal linter because automated checks run on nearly every coding turn and agents can act on rules that humans might find too noisy. Ultracite pairs fast tools such as Oxlint and Oxfmt with strict rules and agent instructions, while keeping judgment-heavy questions for review.

### [I Gave Grok Bot a Remote Computer (8 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fupstash.com%2Fblog%2Fi-gave-grok-bot-a-remote-computer%3Futm_source=tldrdev/1/010001a11b42d0e8-47fd7f13-faf8-4f1c-ab84-8bfbe63867c8-000000/QwsaCw_f2bAmD0BQifcxVL2TGfJrQrpV1-Hm_Hk5nrI=452)
A remote Upstash Box gives Grok Bot a shell, persistent filesystem, GitHub integration, public previews, schedules, snapshots, and optional browser automation through MCP. The examples show it building a live app, cloning and fixing repositories, and turning a Slack report into a Linear ticket and pull request from a phone.

### [input type="password" maxlength="20" Prevents Me from Logging into Vanguard (2 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Ftanin.nanakorn.com%2Finput-type-password-maxlength-20-is-considered-harmful-and-why-i-couldnt-login-into-vanguard%2F%3Futm_source=tldrdev/1/010001a11b42d0e8-47fd7f13-faf8-4f1c-ab84-8bfbe63867c8-000000/eNKfmHpPs-q-QHFpIeQkwFbRcCtgT30MXzgO5vWv3Aw=452)
Vanguard's password reset form silently truncated pasted passwords at 20 characters, while its login form accepted the full value and then rejected it as incorrect. The incident shows why password length limits should be validated visibly in JavaScript or on the server instead of using an HTML maxlength attribute that changes the submitted credential.
