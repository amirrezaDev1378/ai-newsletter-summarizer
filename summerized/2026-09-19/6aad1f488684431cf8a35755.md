### [Kubernetes v1.37: Pod-Level Resource Managers graduated to Beta (2 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fkubernetes.io%2Fblog%2F2026%2F09%2F15%2Fkubernetes-v1-37-pod-level-resource-managers-beta%2F%3Futm_source=tldrdevops/1/010001a0b4422566-6e774009-0cf2-4c38-aa95-b46153b0df04-000000/EHnsiZRDSnBVK-w9CJoCWxI_fUXFXjPDaIiTMHhPuTo=452)

The Pod-Level Resource Managers feature has graduated to Beta status in Kubernetes v1.37. This enhancement allows the Kubelet to use pod-level resource declarations when making hardware placement decisions. It solves a previous limitation where operators had to choose between dedicating physical cores to sidecars or forfeiting NUMA alignment.

### [Running OpenBao on Kubernetes with a CloudNativePG PostgreSQL backend (9 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fwww.cncf.io%2Fblog%2F2026%2F09%2F16%2Frunning-openbao-on-kubernetes-with-a-cloudnativepg-postgresql-backend%2F%3Futm_source=tldrdevops/1/010001a0b4422566-6e774009-0cf2-4c38-aa95-b46153b0df04-000000/qiDEaEBt8sNGFfTbxP-kiQlxL5incY0e7ekRON_knK0=452)

OpenBao and CloudNativePG can manage infrastructure secrets on Kubernetes without vendor lock-in by using certificate authentication and synchronous replication. OpenBao uses the CloudNativePG PostgreSQL cluster as an encrypted key-value store, and a schema-init job revokes default public permissions to lock down the database. CloudNativePG automatically renews client certificates every 90 days, but OpenBao requires a rolling restart to load the new files. The setup runs three OpenBao replicas and three Postgres instances across separate nodes.

## Resources & Tools

### [Browserskill (GitHub Repo)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fgithub.com%2FTencent%2FBrowserSkill%3Futm_source=tldrdevops/1/010001a0b4422566-6e774009-0cf2-4c38-aa95-b46153b0df04-000000/f3PSaXn_EzpmXGsa-b5ZKcAfE-mUThT49VqItIPsxEQ=452)

BrowserSkill connects AI agents such as Cursor, Claude Code, and Codex to a user's logged-in browser. The tool requires agents to explicitly borrow open tabs and return them after finishing a task. It includes a command-line interface, a daemon, and a browser extension.

### [Cline (GitHub Repo)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fgithub.com%2Fcline%2Fcline%3Futm_source=tldrdevops/1/010001a0b4422566-6e774009-0cf2-4c38-aa95-b46153b0df04-000000/hdVmKMHe0UtvY2tCF8r5CzDZCNtG4dVDG3rq6ntbU_M=452)

Cline is an open-source coding agent that runs in IDEs, terminals, and as a native desktop app for macOS and Windows. It reads project structures, edits files, and executes terminal commands with human-in-the-loop approval. Users can switch between Plan and Act modes or use the SDK to build custom tools and coordinate multi-agent teams. The tool runs on any model and supports integrations through plugins or MCP servers.

### [HarnessTax: How Much Does the Harness Matter for Coding Agents? (8 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fharnesstax.github.io%2F%3Futm_source=tldrdevops/1/010001a0b4422566-6e774009-0cf2-4c38-aa95-b46153b0df04-000000/qbyy77OkLD25hVBBOoymM5x82FrUSgcpDExxsywmQFQ=452)

Coding-agent harnesses such as Claude Code, Codex CLI, and Pi can produce similar task success rates while using dramatically different amounts of tokens and money. Across 21 model–harness combinations on SWE-bench Lite and Terminal-Bench 2.0, harness choice changed cost by as much as 5×, and the model provider's own harness was not consistently the most efficient option.

### [Getting started with runtime security and Falco (11 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fwebflow.sysdig.com%2Fblog%2Fintro-runtime-security-falco%3Futm_source=tldrdevops/1/010001a0b4422566-6e774009-0cf2-4c38-aa95-b46153b0df04-000000/F7jzVur-yq8VERgn1ZsLPUutjIcxKq3T5unpFEmupAk=452)

Runtime security protects cloud workloads while they are executing, filling gaps that posture management cannot catch, such as zero-days, privilege escalation, and compromised credentials. Falco provides cloud-native runtime detection across hosts, containers, Kubernetes, and cloud services by analyzing system calls and plugin events, adding contextual alerts, and deploying easily with Helm.

### [Komodor Extends AI SRE Reach for Kubernetes to AI Agents (3 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fcloudnativenow.com%2Ffeatures%2Fkomodor-extends-ai-sre-reach-for-kubernetes-to-ai-agents%2F%3Futm_source=tldrdevops/1/010001a0b4422566-6e774009-0cf2-4c38-aa95-b46153b0df04-000000/L5Nq449Ho3KL_OBP8gRRf2Nxtetr6qDnFEynPs0rie0=452)
