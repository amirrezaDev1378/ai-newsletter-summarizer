## News & Trends

### [Announcing AWS Lambda Web Functions (5 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Faws.amazon.com%2Fblogs%2Faws%2Fannouncing-aws-lambda-web-functions-for-fast-consistent-web-app-performance-anywhere%2F%3Futm_source=tldrdevops/1/010001a13a284170-fd246ada-e85b-41d6-b7ff-4cd28f1ac2e5-000000/ygVRhVQoQ9dpquL29a-MGg5r0tiB0t_NCNv7xQIOZtg=452)

AWS Lambda Web Functions is a new form factor that runs standard HTTP web applications without rewriting code into an event handler. Developers can deploy existing Node.js servers built with frameworks like Express or Next.js, and the service automatically handles scaling and multi-region distribution. Each execution environment handles up to 128 concurrent requests, and billing is based on active CPU time rather than total duration. It is available today in five regions.

### [SRE book second edition (3 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fcloud.google.com%2Fblog%2Fproducts%2Fdevops-sre%2Fsre-book-second-edition%2F%3Futm_source=tldrdevops/1/010001a13a284170-fd246ada-e85b-41d6-b7ff-4cd28f1ac2e5-000000/i3uBQzUSaFEg5PzMnoi-ohZAYFH7vEBFywlZ_8K3LI0=452)

Google has released a completely rewritten second edition of its Site Reliability Engineering book with O'Reilly Media. The update reflects a decade of changes to the reliability field, including the rise of AI, microservices, and platform engineering. The new text includes guidance on modern challenges like running large language models and using AI to enhance operational reliability.

## Miscellaneous

### [Shipping Media Over QUIC at Meta Scale for Instagram Live Ingest (6 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fengineering.fb.com%2F2026%2F10%2F12%2Fvideo-engineering%2Fshipping-media-over-quic-at-meta-scale-for-instagram-live-ingest%2F%3Futm_source=tldrdevops/1/010001a13a284170-fd246ada-e85b-41d6-b7ff-4cd28f1ac2e5-000000/EBE8Ci_XCQnCo9D0xlk-rL8fFFv1Bu9Lzdo7P8o9wWA=452)

Instagram Live now uses the open standard Media over QUIC (MoQ) protocol for live video ingest on iOS and Android. This switch moves development from Meta's in-house RUSH protocol to a shared IETF standard developed with Google, Akamai, and others. Meta says the MoQ path matched RUSH on streaming quality and reliability measures during testing.

### [What gets TOASTed in Postgres (12 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fplanetscale.com%2Fblog%2Fwhat-gets-toasted-in-postgres%3Futm_source=tldrdevops/1/010001a13a284170-fd246ada-e85b-41d6-b7ff-4cd28f1ac2e5-000000/TUD5xXtLJHOBSMAbaJHB7m0c0PNZ4wZoucMXZYCdlFo=452)

Postgres TOAST compresses oversized variable-length values and moves them into separate storage when necessary. SQL examples show why LZ4's faster compression does not always produce smaller values or faster reads: pglz can outperform it for short previews, while uncompressed external storage can improve reads from the middle of large binary values.
