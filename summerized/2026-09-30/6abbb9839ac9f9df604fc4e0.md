### [CISA Says Attackers Are Exploiting Two Critical Citrix NetScaler Flaws Globally (2 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fthehackernews.com%2F2026%2F09%2Fcisa-says-attackers-are-exploiting-two.html%3Futm_source=tldrinfosec/1/010001a0ed4c932d-abd62a70-3349-4a92-acc7-344bb9cfcfab-000000/qiN6_L-Q0TAXlqklYNAyTTrcXWor5WXbqUijlaBwsW8=452)
CISA added CVE-2026-88771 and CVE-2026-88772 to its KEV catalog after confirming global exploitation. Both have CVSS scores of 9.5 and enable unauthenticated command execution, remote code execution, or denial of service. CVE-2026-88772 requires DTLS, which VPN virtual servers enable by default. Administrators should patch, inspect for compromise, isolate affected appliances, revoke access, rotate secrets, and investigate connected systems.

## 🧠 Strategies & Tactics

### [Containers Are No Longer a Security Boundary (6 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fdepthfirst.com%2Fresearch%2Fcontainers-are-no-longer-safe%3Futm_source=tldrinfosec/1/010001a0ed4c932d-abd62a70-3349-4a92-acc7-344bb9cfcfab-000000/JKlak5e8RYH9jzotnMsFbjLkq6fiXRCdeaouX2cQ5yM=452)
The traditional view of containers as a strong isolation mechanism is being eroded by kernel vulnerabilities. This article explores how a recent AF_UNIX subsystem vulnerability can be leveraged for container escapes and recommends shifting untrusted workloads to MicroVMs like Firecracker or Kata Containers.

### [PolinRider is A/B Testing its Way Past Your Detections (11 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fopensourcemalware.com%2Fblog%2Fpolinrider-is-a-b-testing-its-way-past-your-detections%3Futm_source=tldrinfosec/1/010001a0ed4c932d-abd62a70-3349-4a92-acc7-344bb9cfcfab-000000/K95jtH8xecrDCDcyGkYNqmvr_pj7dM2C5Ml6_YJE5Pc=452)
DPRK's PolinRider malware has been spreading via GitHub by force-pushing rewritten commits that plant VS Code tasks running obfuscated JavaScript disguised as font files. OpenSourceMalware traced parallel variants running A/B tests with different paths and obfuscators. Defenders are advised to flag fake fonts via file content, scan branches through bare clones, and enforce signed commits and force-push blocking.

### [From Exposure to Lockdown: How AWS Neutralizes Compromised IAM Credentials through Managed Policies (15 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Funit42.paloaltonetworks.com%2Fdetecting-exposed-aws-iam-credentials%2F%3Futm_source=tldrinfosec/1/010001a0ed4c932d-abd62a70-3349-4a92-acc7-344bb9cfcfab-000000/3UYnhPCoMIIx1xgr9NfX_VWERS5o6cfIEE5kzC1XnwQ=452)
AWS automatically attaches the `AWSCompromisedKeyQuarantineV3` managed policy to exposed IAM users within 10 seconds of a public GitHub push. Security teams should treat quarantine events as confirmation of active key exposure, alert on unexpected `AttachUserPolicy` events, and rotate credentials before removing the policy.

### [Sender spoofing in Proton Mail via display-name homograph (3 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Falonsovidales.github.io%2Fprotonmail-sender-spoofing%2F%3Futm_source=tldrinfosec/1/010001a0ed4c932d-abd62a70-3349-4a92-acc7-344bb9cfcfab-000000/2sFjKcFbc6QvhcRhxMKHCECranwIxCOZgkmAUiimuvE=452)
