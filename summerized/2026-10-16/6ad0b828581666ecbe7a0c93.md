## Articles & Tutorials

### [The Most Common Questions About Agent Evals, Answered (8 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fwww.langchain.com%2Fblog%2Fcommon-questions-about-agent-evals%3Futm_source=tldrdev/1/010001a13f4f4e1d-ed91d087-54d7-4f8e-805a-19df5e1d6522-000000/8flWENuRtJ5nxJmcVrFOX0dO5zIifhtXKQYq2ydzZ6A=452)

Agent evals score runs against desired behaviors, but exact-output tests often fail because agent outputs and paths vary. The guide recommends starting with 10 to 20 examples drawn from traces, combining code evaluators with LLM judges and human review, and using offline and online evals at different stages.

### [Lazy Loading Images and Media: How Far Ahead Browsers Fetch (6 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fcalibreapp.com%2Fblog%2Fnative-lazy-loading%3Futm_source=tldrdev/1/010001a13f4f4e1d-ed91d087-54d7-4f8e-805a-19df5e1d6522-000000/CvtHywsbLr3V-k430NbG1Z6Nd4jk6qqENoQuEB7_4ro=452)

Browsers fetch lazy-loaded media at different distances, with Chrome adjusting its margin based on connection speed, Firefox using a fixed 600-pixel threshold, and Safari applying a viewport-based threshold to images. The article explains why the largest contentful paint image should load eagerly and why media dimensions should be reserved to prevent layout shifts. Its practical takeaway is to use native lazy loading selectively, based on how far ahead each browser fetches.

### [From 2,500 requests to 24: Rebuilding star history without the stargazers (7 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fgithub.blog%2Fengineering%2Farchitecture-optimization%2Ffrom-2500-requests-to-24-rebuilding-star-history-without-the-stargazers%2F%3Futm_source=tldrdev/1/010001a13f4f4e1d-ed91d087-54d7-4f8e-805a-19df5e1d6522-000000/BxGYtDjr1gH6VSywHPsa4ZayP3ZQT94DrI7dAdxLFLE=452)

GitHub rebuilt its star-history API to return up to 30 weeks of daily counts in one request. Maintainers can track a project's momentum without exposing stargazer identities, which could be scraped for spam or phishing. To avoid simply shifting the cost to count queries, the endpoint filters stars by time before counting, reducing database work.

### [Pure UI in the Agentic Era (6 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fmattrothenberg.com%2Fnotes%2Fpure-ui-agentic-era%2F%3Futm_source=tldrdev/1/010001a13f4f4e1d-ed91d087-54d7-4f8e-805a-19df5e1d6522-000000/cEUNW4IogwNYJkNumDKQ30m11cdyxRKK9zkYSQzgVIQ=452)

The article revisits the idea that UI should be a pure function of state and explains why it matters for agent-written interfaces. Passing roles, plans, billing status, and feature flags explicitly lets teams render and inspect each state combination before release.

### [Passkeys Are Not a Trap (4 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fscotthelme.co.uk%2Fpasskeys-are-not-a-trap%2F%3Futm_source=tldrdev/1/010001a13f4f4e1d-ed91d087-54d7-4f8e-805a-19df5e1d6522-000000/IsO1xaQmJd3RNctwehz5Yonp9zCKhr0h9f3ib_zo1-U=452)

Synced consumer passkeys generally return no attestation, and WebAuthn attestation identifies an authenticator model rather than a user's operating system, browser, or firmware. The response argues that passkeys remain more phishing-resistant than TOTP and recommends continuing to use them.

## Launches & Tools

### [OpenCode 2.0 (7 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fanoma.ly%2Fnotes%2Fopencode-2-0%2F%3Futm_source=tldrdev/1/010001a13f4f4e1d-ed91d087-54d7-4f8e-805a-19df5e1d6522-000000/se91PD7yjlJKxPbRtKBo8YWNVaIBsA0d2Y-13YXTaSw=452)

It also adds background tasks and subagents, expands the plugin system, and includes breaking changes for 1.0 plugins and the server API.

### [Jev: For the builders AND dreamers (4 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Ftypesafe.ai%2Fblog%2Fjev-1-14%3Futm_source=tldrdev/1/010001a13f4f4e1d-ed91d087-54d7-4f8e-805a-19df5e1d6522-000000/nBGyrW2UHZUruP5w2JSJGftHS1Du_CufTy-4GUC_L6s=452)

Jev 1.14 improves the production model and introduces experimental image input, a new type, and longer context behind API “danger zone” flags. TypeSafe describes those features as useful for exploration but too unreliable for production automation.

### [Introducing Grok Voice 3.0 (5 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Flinks.tldrnewsletter.com%2Fs6lcFZ/1/010001a13f4f4e1d-ed91d087-54d7-4f8e-805a-19df5e1d6522-000000/HzYztlgG1wK3SfaoBfTWAGlG2Vyw98e0QxSNJPjixrs=452)
