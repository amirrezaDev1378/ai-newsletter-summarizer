## Articles & Tutorials

* **[How Smart Model Routing Can Cut LLM Costs 10X (13 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fblog.bytebytego.com%2Fp%2Fhow-smart-model-routing-can-cut-llm%3Futm_source=tldrdev/1/010001a09fade780-0f7a3efc-ab1b-45cb-bd52-b467c12d5242-000000/IhF7RaxlNr4PAUEYDalWSQWnXGhXRIlLvmFU2JO2YE0=452)**
  Smart routing sends routine requests to cheaper models and reserves stronger ones for difficult or high-risk work. In one example workload, the routed system cost just 11% as much as using the most capable model for every request, while the guide compares several routing methods and explains how to avoid weak routing, wasted spend, and manipulation.

* **[Building a Robust Harness for Agents in Production (10 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fengineering.monday.com%2Fbuilding-a-robust-harness-for-agent-in-production-feed-agent-case-study%2F%3Futm_source=tldrdev/1/010001a09fade780-0f7a3efc-ab1b-45cb-bd52-b467c12d5242-000000/2pPIpTDQR7sFsUcUbA5wKksvDTojLRLhlWanrIeKFDk=452)**
  monday.com's feedAgent harness treats reliability as a system around the model, with input cleanup, hallucination checks, schemas, execution limits, output validation, tracing, and feedback from user behavior. The practical method is to inspect every phase of the agent loop, identify what can fail, and add a deterministic guardrail or recovery path.

* **[If Coding Is Solved, What Now? Measuring Code Sloppiness (6 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fearendil.com%2Fposts%2Fmeasuring-code-sloppiness%2F%3Futm_source=tldrdev/1/010001a09fade780-0f7a3efc-ab1b-45cb-bd52-b467c12d5242-000000/5BxcHrQwSKc7CQF9s-ksXIz6DlxtyV0n0jYUx6MePaA=452)**

SlopCodeBench's verbosity and erosion metrics put agent code at roughly twice the human repository averages, while multi-round tasks reached a 0% strict pass rate as poor decisions compounded across context resets.

## Opinions & Advice

* **[We Must Pace the Frontier (22 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fdarioamodei.com%2Fpost%2Fwe-must-pace-the-frontier%3Futm_source=tldrdev/1/010001a09fade780-0f7a3efc-ab1b-45cb-bd52-b467c12d5242-000000/f2TvJYyGTKzW5yUaZnL_47-UHice7dYyQDMNy8VG3Dc=452)**
  This article argues that frontier labs should slow capability gains so safety, interpretability, security, and operational rigor can catch up. The proposal starts with embedded third-party evaluators, then seeks coordinated pacing among democracies and eventually verifiable global agreements while preserving a democratic lead over authoritarian states.

* **[Make It Anyway (5 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fwww.joelotter.com%2Fposts%2F2026%2F09%2Fmake-it-anyway%2F%3Futm_source=tldrdev/1/010001a09fade780-0f7a3efc-ab1b-45cb-bd52-b467c12d5242-000000/Zd-MFuMBKniLFWHqFhG_fxBWYyPrRqIQofssiR8QdLA=452)**

* **[Maybe We Shouldn't Be Reviewing All This Code (6 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fmartinfowler.com%2Frachels-ramblings%2Fcode-review.html%3Futm_source=tldrdev/1/010001a09fade780-0f7a3efc-ab1b-45cb-bd52-b467c12d5242-000000/R6T7UvcEZXvgrLuDd-q5SJK2kKN1KOB3E4Go5nLAM8A=452)**

## Launches & Tools

* **[AgentsDock (Website)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fagentsdock.net%2F%3Futm_source=tldrdev/1/010001a09fade780-0f7a3efc-ab1b-45cb-bd52-b467c12d5242-000000/_RuXDF6WJewKu_VV97hbaKlZcXUm3GB_NE4tVQomwgM=452)**
  AgentsDock is a self-hosted workspace for running Claude Code and Codex on machines you control while accessing them from desktop and mobile clients. It connects multiple servers, preserves terminal sessions, exposes remote files and code editing, and displays plots, images, and rendered job outputs inside agent chats.

* **[Real-SWE (Website)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fwithspecific.com%2Fbenchmarks%2Freal-swe%3Futm_source=tldrdev/1/010001a09fade780-0f7a3efc-ab1b-45cb-bd52-b467c12d5242-000000/-DF26AXSGF07yLdUGwEN3bsBzfIblpvn515pGXg9658=452)**
  Real-SWE evaluates model and harness pairs on ten tasks from licensed private production codebases, including business rules and company-specific conventions that cannot be recovered from public training data. Across 640 rollouts, the top configuration resolved 38.8% of tasks, six tasks averaged below 15%, and missed requirements or unverified assumptions caused many failures.

* **[Give Your Coding Agents a Memory You Own (9 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fhuggingface.co%2Fblog%2Ffunes%3Futm_source=tldrdev/1/010001a09fade780-0f7a3efc-ab1b-45cb-bd52-b467c12d5242-000000/2nM56fJa-rtVEB4vTk6Ks84z8RzuM24BOaYa_pyRdq4=452)**
  funes indexes agent session traces locally with vector search, BM25, and cross-encoder reranking, then returns the original text with provenance instead of summaries. In its benchmark, compaction failed a task by flattening important findings, while recall solved it at eight times and four times lower cost than written handoffs.
