## 🔓 Attacks & Vulnerabilities

### [Warlock Ransomware Hits Large Spanish, Portuguese Orgs (3 minute read)](https://links.tldrnewsletter.com/jRXOab)

Warlock (also tracked as Longlegs and Storm-2603) recently targeted four Spanish- and Portuguese-speaking organizations over a two-month span, including a water utility, a telecom provider, a regional government, and a university. The threat group exploits Microsoft SharePoint vulnerabilities, then leverages DLL sideloading, vulnerable drivers, VS Code remote tunnels, and SYSVOL replication to propagate ransomware across Active Directory environments.

### [Hacks of 2 federal agencies in a month have spilled a bonanza of sensitive data (3 minute read)](https://arstechnica.com/security/2026/10/hacks-of-2-federal-agencies-in-a-month-have-spilled-a-bonanza-of-sensitive-data/?utm_source=tldrinfosec)

The Pentagon disclosed that a months-long intrusion exposed records belonging to 2.8 million living individuals. The stolen Defense Manpower Data Center data included Social Security numbers, addresses, demographics, and military specialties. Additionally, ShinyHunters claimed responsibility for leaking FBI employee records, detailing roles related to investigations of China and Russia. Officials have not commented on the entry point, attacker contact, or ransom demands.

### [Vercel Confirms KVM Zero-Day VM Escape, Awards Researcher $50,000 (3 minute read)](https://cybersecuritynews.com/kvm-zero-day-vm-escape/?utm_source=tldrinfosec)

A KVM zero-day reported by researcher Paulos Yibelo allowed guest code to achieve root access on the host, compromising the Firecracker microVM boundary used by Vercel Sandbox to isolate untrusted workloads and AI agents. Vercel CEO Guillermo Rauch confirmed the vulnerability and the $50,000 maximum bug bounty payout, though specific CVEs, affected kernel versions, or patches remain undisclosed pending a detailed write-up.

## 🧠 Strategies & Tactics

### [GitHub Repos Exposed 543,699 Credentials. Nobody Revoked Them (12 minute read)](https://trufflesecurity.com/blog/github-repos-exposed-543699-credentials-nobody-revoked-them?utm_source=tldrinfosec)

In a July scan of 224 million public GitHub repositories, Truffle Security verified 543,699 active credentials, with the median token exposed for 784 days and some dating back to 2009. While GitHub push protection reduced leaks of recognized tokens by 53%, connection strings, private keys, and Google API keys escaped detection—accounting for 51.8% of live credentials found. 

### [How we release Fastify packages without npm tokens (8 minute read)](https://backend.cafe/how-we-release-fastify-packages-without-npm-tokens)

Fastify transitioned roughly 100 repositories from manual local releases to GitHub Actions using npm Trusted Publishers. This approach replaces long-lived npm tokens with short-lived OIDC tokens bound directly to specific repositories, workflows, and environments. Releases are manually triggered via `workflow_dispatch`, require approval from the release team, and are published with cryptographic provenance.

### [DeepSeek-Reasonix: How a poisoned config can hijack an AI coding agent (7 minute read)](https://about.gitlab.com/blog/deepseek-reasonix-vulnerability-discovered/?utm_source=tldrinfosec)

A configuration poisoning vulnerability (CVE-2026-102437) enabled arbitrary command execution when developers viewed file diffs in DeepSeek-Reasonix Studio. The issue arose because a `.gitattributes` entry routed files through a command specified in a poisoned `.git/config` that the tool's git wrapper failed to override. GitLab recommends updating to Studio 2.21.0 or npm 1.39.3, and advises builders of git-wrapping tools to explicitly override command-executing config keys during execution.
