### [Why I'm Still Bearish on LLMs After Navier-Stokes (6 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fdank.systems%2Fposts%2F2026-09-15-ai-bear.html%3Futm_source=tldrdev/1/010001a0a9fa2853-17754f3a-4e6c-40d7-b195-1a2ee56de1ed-000000/UVhHvBYS-U8jog85sy2j3Rocdl8oEsUrMJ4BG60YNyE=452)
Frontier models can produce great results on tightly specified tasks, but most knowledge work lacks cheap, rigorous verification. ## Miscellaneous

### [We Wanted to Use Baseten for Inference. We Ended Up With Admin Access to Baseten GitHub Repos (8 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fwww.strix.ai%2Fblog%2Fbaseten-harbor-github-pat-takeover%3Futm_source=tldrdev/1/010001a0a9fa2853-17754f3a-4e6c-40d7-b195-1a2ee56de1ed-000000/cY1bX9sypa4HmwZmPEaN56XH1Zn7hSswOJQJDHldCoY=452)
An autonomous security scan found a public Harbor registry, then recovered a live GitHub token from a 2023 container image's build history. The token still had broad admin and write access, showing why teams must inspect image metadata as well as layers, use BuildKit secret mounts, expire credentials, and minimize scopes.

### [Learning to Solve Hard Problems in RL for LLMs by Never Giving Up (11 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fmnoukhov.github.io%2Fposts%2Fngu%2F%3Futm_source=tldrdev/1/010001a0a9fa2853-17754f3a-4e6c-40d7-b195-1a2ee56de1ed-000000/zG03ZeQktfjPxDEij_3gIS7avRHftpBK8uPWqpm_uqs=452)
Standard RL post-training disproportionately improves problems the base model already solves, a pattern the piece calls the Matthew Effect. Never Give Up counters it by continuing to sample hard examples, with experiments across math and code showing better gains on previously unsolved tasks while introducing tradeoffs around asynchronous staleness and compute.

### [The AI Inference Revolution Is Here (12 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fspectrum.ieee.org%2Finference-hardware-revolution%3Futm_source=tldrdev/1/010001a0a9fa2853-17754f3a-4e6c-40d7-b195-1a2ee56de1ed-000000/gBQXzVEtYNKL1RBkP4dxAm5ToSCjVivFvdgaMlQ5pd8=452)
Inference demand is shifting hardware design toward memory bandwidth, specialized decode chips, wafer-scale systems, stacked memory, and aggressive quantization. Prefill and decode favor different architectures. Future systems may combine several chip types rather than rely on one universal accelerator.
