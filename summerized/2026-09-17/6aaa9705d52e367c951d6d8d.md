# TLDR Information Security 2026-09-16

## 🔓 Attacks & Vulnerabilities

### [A Peripheral Path to SYSTEM - Exploiting Logi Options+ for SYSTEM Shells (7 minute read)](https://blog.amberwolf.com/blog/2026/september/a-peripheral-path-to-system---exploiting-logi-options%2B-for-system-shells/?utm_source=tldrinfosec)

Logi Options+, Logitech's widely used app for configuring mice and keyboards, allowed any standard Windows user to reach SYSTEM because its privileged updater trusted pipe connections from an agent process the user could inject. AmberWolf researchers used this access to override the `{depot}` path via the reinstall IPC endpoint, directing a SYSTEM `msiexec` call to an unsigned MSI that skipped signature checks since the manifest set `isSystem` to true. Tracked as CVE-2026-12518 and patched on August 19, administrators should verify that fleets are running a newer build and set alerts on `msiexec` spawned by `logioptionsplus_updater.exe` from user-writable paths.

### [ClickFix attacks are tricking Mac and Windows users into hacking themselves (2 minute read)](https://techcrunch.com/2026/09/14/clickfix-attacks-are-tricking-mac-and-windows-users-into-hacking-themselves/?utm_source=tldrinfosec)

Attackers hijacked an HBO Max Reddit advertising account to post malicious ads leading to fake HBO Max pages with CAPTCHA-style ClickFix prompts. Victims were tricked into copying commands into Windows Command Prompt, PowerShell, or macOS Terminal, installing infostealers that targeted passwords, active sessions, and crypto wallets. Reddit paused the ads three days after a user flagged them; the method of the account takeover remains unknown.

### [Mass-Scanning Campaign Exploits Vite Flaw to Extract Cloud Credentials From Exposed Dev Servers (2 minute read)](https://thehackernews.com/2026/09/mass-scanning-campaign-exploits-vite.html?utm_source=tldrinfosec)

In August, attackers scanned exposed Vite development servers and exploited CVE-2026-39364. Crafted query parameters bypassed `server.fs.deny`, returning protected files through `/@fs/`. Observed targets included `.env` files, AWS credentials, Azure profiles, Terraform state, database passwords, and `/proc` data, utilizing requests with spoofed crawler user agents and forged forwarding headers.

## 🧠 Strategies & Tactics

### [FulcrumSec - A look at their tradecraft (8 minute read)](https://www.aitmfeed.com/blog/blog-1/fulcrumsec-a-look-at-their-tradecraft-20?utm_source=tldrinfosec)

FulcrumSec, a financially motivated data extortion gang linked to breaches at Manchester Airports Group, Arup, and Novo Nordisk, reportedly operates up to 250 servers scanning client-side JavaScript and fresh vulnerabilities like React2Shell, bulk-testing harvested credentials before selecting targets. They pivot through GitHub repositories, AWS, Azure, and Secrets Manager without touching endpoints. For example, a single Arup PAT reportedly opened roughly 10,000 private repositories. Defenders should baseline normal identity behavior and flag tokens that rapidly clone thousands of repos or enumerate unrelated secrets from unfamiliar infrastructure.

### [Beltdown2: Escaping the Cursor CLI sandbox (7 minute read)](https://www.accomplish.ai/blog/beltdown2-escaping-the-cursor-cli-sandbox/?utm_source=tldrinfosec)

A malicious workspace could place a `core.fsmonitor` hook in `.git/config` to exploit Cursor CLI running internal Git commands outside its macOS Seatbelt sandbox. A read-only prompt triggered `git ls-files`, executing the hook and enabling the proof payload to write to `$HOME` where sandboxed shell commands normally could not. Anysphere released Cursor CLI `2026.08.04-aaa8809`, injecting `GIT_CONFIG` environment settings into every Git spawn to disable `core.fsmonitor`, custom hooks, and repository attributes.

### [Unmasking Cloud Identities: From Behavioral Clustering to Automated Detection (11 minute read)](https://unit42.paloaltonetworks.com/behavioral-clustering-map-to-cloud-identities/?utm_source=tldrinfosec)

Unit 42 analyzed CloudTrail activity across more than 40,000 identities in 125 AWS environments, discovering they fall into consistent functional roles (console admins, CI/CD runners, backup agents, security tools) regardless of naming conventions or assigned IAM policies. Because attackers frequently hide behind benign labels and existing permissions, a backup service suddenly executing administrative actions stands out even if its permissions technically allow it. This behavioral pattern distills into a lightweight SQL classifier, enabling teams to tag identity roles at scale without an extensive ML pipeline.

## 🧑‍💻 Launches & Tools

### [OpenHunterAI (GitHub Repo)](https://github.com/LumosLab-Innovation/OpenHunterAI?utm_source=tldrinfosec)

OpenHunterAI is a local AI red-team workspace for conducting attacker-style assessments against web apps, APIs, and LLM applications. It combines browser inspection, recon, ZAP, and a Nuclei adapter into a single scan plan. Key features include scope control with domain verification, deterministic plans, and human approval gates prior to sensitive validation runs. It also integrates as a skill for Claude Code, Codex, and Gemini CLI.

### [RF-Swift (GitHub Repo)](https://github.com/PentHertz/RF-Swift?utm_source=tldrinfosec)

A multi-platform RF toolbox designed to deploy specialized radio, hardware, and security tools on Linux, Windows, and macOS. It supports x86_64, ARM64 (Raspberry Pi and Apple Silicon), and RISC-V architectures without impacting the primary OS.

### [AIUC (Product Launch)](https://aiuc.com/?utm_source=tldrinfosec)

AIUC audits and certifies deployed AI agents against its AIUC-1 standard using roughly 5,000 tests covering jailbreaks, hallucinations, and data leaks. Customers receive a 100-page report, with human verification of final audit results.

## 🎪 Miscellaneous

### [Two DGX Sparks, 33 Local Models, One Question: Can Local AI Actually Red Team? (38 minute read)](https://betheadversary.com/posts/dgx_spark_red_team_bench/?utm_source=tldrinfosec)

Roei Sherman evaluated 33 local models on a two-node DGX Spark cluster for red-teaming capabilities using a security capability test, a red team willingness/accuracy benchmark, and a coding benchmark (Aider Polyglot plus two custom suites). Mixture of Experts (MoE) models consistently outperformed their model class across all three benchmarks, with `Qwen3.6-35B-A3B (FP8)` leading the security capability benchmark and `Qwen3-Coder-Next (FP8)` winning the coding benchmark.

### [Mythic C2 Activity at Internet Scale (5 minute read)](https://censys.com/blog/mythic-c2?utm_source=tldrinfosec)

Censys research tracked 131 internet-exposed Mythic C2 hosts, finding that 115 still retained default `O="Mythic"` or `O="Mythic C2"` certificates. One identified cluster paired Mythic with custom Rust implants, Discord-based C2, and a domain disguised as Windows telemetry traffic.
