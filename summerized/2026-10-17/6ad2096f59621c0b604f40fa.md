### [Inside Hyperdrive: How We Solved a Rare MySQL Caching Bug (10 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fblog.cloudflare.com%2Fhyperdrive-mysql%2F%3Futm_source=tldrdevops/1/010001a14474c7d0-e41a6800-43f3-4920-a776-1f388af1c7ee-000000/3wcs6sj9uXVicj-Y4NVrI0GtOeRMIkkM1QcYvrLDSgo=452)
A rare Hyperdrive bug returned empty MySQL results when two components shared a cache but encoded responses using different protocol capabilities. Cloudflare traced the failures to an assumption inherited from its Postgres implementation and fixed them by storing responses in a canonical format before translating them for each client.

## Resources & Tools

### [Tokenspeed (GitHub Repo)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fgithub.com%2Flightseekorg%2Ftokenspeed%3Futm_source=tldrdevops/1/010001a14474c7d0-e41a6800-43f3-4920-a776-1f388af1c7ee-000000/x9qzYO3MI0Z_EKEeRGaj9_KAUGFpyTBsXaDVgjS-HW0=452)

It is the first inference engine to separate the control plane, implemented in C++, from the execution plane, implemented in Python. The project is backed by the non-profit LightSeek Foundation with support from vendors including NVIDIA and AMD.

### [Pulumi ESC now issues OIDC tokens for any service (5 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fwww.pulumi.com%2Fblog%2Fesc-oidc-tokens-for-any-service%2F%3Futm_source=tldrdevops/1/010001a14474c7d0-e41a6800-43f3-4920-a776-1f388af1c7ee-000000/3WQ8O8VepqGz5aK0U18hc2V3GNVJrRoCnLsErMI2Q24=452)
Pulumi ESC environments can now mint short-lived OpenID Connect (OIDC) tokens for any service that accepts one. The new fn::open::oidc provider generates tokens that expire within one hour, eliminating the security risks associated with storing long-lived API keys. Developers can use these tokens to authenticate with services like Anthropic, Cloudsmith, JFrog Artifactory, and Aembit without storing static credentials. The feature is available now in every Pulumi Cloud organization.
