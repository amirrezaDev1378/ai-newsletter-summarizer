## Articles & Tutorials

* **[Build Your Own Decision Model (5 minute read)](https://nishtahir.com/build-your-own-decision-model/?utm_source=tldrdev)**
  A Qwen3-1.7B walkthrough turns multiple-choice questions into single-pass predictions by scoring only the allowed answer tokens. Fine-tuning improves accuracy on a 1,221-question CommonsenseQA sample from 59.4% to 62.4%, while temperature scaling makes the model's confidence better reflect its actual accuracy.

* **[How to Effectively Debug When You No Longer Understand the Code (63 minute read)](https://copyconstruct.medium.com/how-to-effectively-debug-when-you-no-longer-understand-the-code-bd3dcb2c5f7b?utm_source=tldrdev)**
  Three production investigations, a latency regression, a memory leak, and a kernel-level hang, show how to steer coding agents through unfamiliar systems using runtime evidence. The framework separates facts from hypotheses, compares failures with a control, and requires every proposed cause to satisfy all known constraints. Adversarial reviews should seek contradictions, and reproductions must match the real failure's signals before they can be trusted.

* **[Five Months Treating Bugs Like Patients and Coding Agents Like a Medical Team (20 minute read)](https://www.cockroachlabs.com/blog/experiment-running-hospital-code/?utm_source=tldrdev)**
  Cockroach Labs structures coding agents around a teaching hospital, with reviewed plans, separate implementation and review roles, structured handoffs, and an audit before merge. The pipeline landed over a million lines of code in five months with seven reverts, and human approval became mandatory after the first autonomous week before the team used it to build customer-facing migration tooling.

## Launches & Tools

* **[REA (Website)](https://rea.tools/?utm_source=tldrdev)**
  REA gives coding agents tools to reverse engineer native binaries, JavaScript and Electron applications, and browser behavior. Its examples recover Windows Calculator's percentage rules and a browser game's acceleration logic, then use those findings to explain or rebuild the features.

* **[Talorys (GitHub Repo)](https://github.com/rociiu/talorys?utm_source=tldrdev)**
  Talorys is a single-user personal AI assistant that runs in your own Cloudflare account and deploys with one command. It combines chat, editable memory, tasks, notes, projects, and scheduled reminders, with core organizational features continuing to work when AI is unavailable.

* **[Big Arrow on the Screen (GitHub Repo)](https://github.com/franzenzenhofer/big-arrow-on-the-screen?utm_source=tldrdev)**
  A macOS command-line tool lets coding agents draw temporary arrows, boxes, and text over the screen to show users where to click. Its transparent overlays allow clicks through to the underlying application and disappear automatically, with skills provided for Claude Code and Codex.

## Miscellaneous

* **[Deno Is Joining Cloudflare (3 minute read)](https://deno.com/blog/cloudflare?utm_source=tldrdev)**
  The Deno team is joining Cloudflare to focus on a shared platform built around Workers, Durable Objects, and celld. Deno runtime development will end after one year of bug fixes and security updates, Deno Deploy will shut down in six months, and JSR will continue operating on Cloudflare infrastructure.

* **[Speculative Decoding: The Art of Guessing Well (70 minute read)](https://astralord.github.io/posts/speculative-decoding-the-art-of-guessing-well/?utm_source=tldrdev)**
  Speculative decoding accelerates generation by drafting several tokens cheaply and verifying them in one target-model pass while preserving the target's output distribution. This detailed walkthrough derives acceptance and speedup formulas, covers EAGLE-3, multi-token prediction, and diffusion drafters, and explains why training for acceptance is different from simply minimizing KL divergence.

* **[The Dirty Pages Surprise: When a Read-Only Query Writes Terabytes (10 minute read)](https://swingbit.github.io/dirty_pages/?utm_source=tldrdev)**
  A MonetDB count-distinct query saturates an NVMe drive with writes because Linux flushes dirty pages from temporary memory-mapped scratch files. Moving the scratch files to tmpfs cuts runtime from 73 minutes to 97 seconds, while workload-specific writeback tuning reaches about 100 seconds without moving them off disk.
