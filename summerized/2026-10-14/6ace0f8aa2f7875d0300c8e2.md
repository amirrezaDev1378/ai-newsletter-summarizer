### [Meta launches Muse Wonder and Wonder Full for AI agents (2 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fwww.testingcatalog.com%2Fmeta-launches-muse-wonder-and-wonder-full-for-ai-agents%2F%3Futm_source=tldrnewsletter/1/010001a134ec9f16-14845891-20a5-4907-bad0-f1318eef13d6-000000/Rwl06uNEObJcvt2n_aRhL3yllqKVnAM0EG7tt0Vjoq0=452)

Muse Wonder is now available through the Meta Model API and Muse Code, while Muse Wonder Full is exclusive to Muse Code subscribers. These new models combine Active Memory—which retains personal context and retrieves relevant details across conversations—with Active Focus, a feature that helps the model navigate complex goals by testing alternative approaches, resolving blockers, adapting to new data, and asking clarifying questions. Meta claims Muse Wonder is its most aligned model to date.

### [Microsoft Prepares to Put Gigawatts of Its Chips in Data Centers (3 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Flinks.tldrnewsletter.com%2F4D2YBX/1/010001a134ec9f16-14845891-20a5-4907-bad0-f1318eef13d6-000000/4AnIuuZkfMALb-vIhJ8Qcxp_vfGOUZbuZUxi8wblQb0=452)

Microsoft is set to roll out its newest Maia chips next year. The Maia 300, built for inference, will be deployed across multiple gigawatts of server capacity in Microsoft data centers. Delivering 40% more tokens per megawatt than leading GPU systems, the Maia chips will not currently be rented directly as cloud computing power to external customers.
