# TLDR Information Security 2026-09-09

## 🔓 Attacks & Vulnerabilities

### [WeWorm](https://calif.io/research/weworm?utm_source=tldrinfosec) (4 minute read)
Calif demonstrated a zero-click worm that takes over WeChat accounts via unanswered VoIP calls. The exploit uses a memory corruption bug in WeChat’s VoIP stack. Once an account is compromised, it automatically calls the victim’s contacts to spread further. Tencent has released mitigations in server-side updates and client versions Android 8.0.77 and iOS 8.0.76.

### [220M Traveler Records Exposed in Vietnam-Linked APIS Leak](https://links.tldrnewsletter.com/NEF1Xc) (2 minute read)
Security researchers discovered an exposed Elasticsearch cluster containing an Advanced Passenger Information System (APIS) database. The leak exposed records for 220 million passengers and crew members, including names, dates of birth, nationalities, and passport numbers. Access was gained via a cloud-based path that accepted default credentials.

### [Hackers Breach F5 BIG-IP APM Devices to Deploy Linux Rootkit](https://links.tldrnewsletter.com/IvoITh) (2 minute read)
A malware campaign known as "PoisonedRefresh" is targeting F5 BIG-IP APM devices. By exploiting a critical RCE vulnerability, attackers inject a fileless web shell and a Linux rootkit by infecting the Apache executable and modifying SELinux configurations.

## 🧠 Strategies & Tactics

### [Hacking AI customer service agents](https://www.intigriti.com/researchers/blog/hacking-tools/hacking-ai-customer-service-agents?utm_source=tldrinfosec) (11 minute read)
Researchers demonstrated various attack vectors against AI support agents, including email spoofing, duplicate headers, and email-address parser mismatches. These vulnerabilities can lead to unauthorized profile changes, refunds, or account data disclosure. Automated processing can also be misled by hidden instructions in MIME parts or CSS-hidden text.

### [RFD 301: Key-hierarchy strategy for rack-level security](https://rfd.shared.oxide.computer/rfd/0301?utm_source=tldrinfosec) (12 minute read)
Oxide has published its design for protecting rack data at rest. The system roots security in a Shamir-shared rack secret, requiring an attacker to steal multiple drives or sleds to recover data. It utilizes HKDF for deriving per-drive ZFS wrapper keys, ensuring that a single compromised disk does not expose the entire rack.

### [Cross-Account Data Leakage in ChatGPT](https://research.checkpoint.com/2026/the-shared-clipboard-inside-the-sandbox-cross-account-data-leakage-in-chatgpt/?utm_source=tldrinfosec) (10 minute read)
Check Point Research found that ChatGPT code-execution containers could use package metadata as a covert channel for cross-account data leakage. This allowed attackers to pull data from a victim's connected Gmail via shared internal services. OpenAI has since decommissioned the vulnerable Artifactory instance.

## 🛠️ Launches & Tools

### [Prism-platform (GitHub Repo)](https://github.com/NovaCode37/Prism-platform?utm_source=tldrinfosec)
An all-in-one OSINT platform featuring over 22 modules, AI analysis, a real-time dashboard, and OPSEC scoring for scanning domains, IPs, emails, and usernames.

### [Sage (GitHub Repo)](https://github.com/gendigitalinc/sage?utm_source=tldrinfosec)
A security tool from Gen Digital that intercepts and blocks dangerous tool calls made by AI coding assistants. It features URL reputation checks, 300+ local heuristics for risky commands, and prompt injection detection.

### [DecBench (Website)](https://decbench.com/?utm_source=tldrinfosec)
A living benchmark that scores decompilers and LLMs on their ability to recover exact source code, measuring perfect-match percentages across various datasets.
