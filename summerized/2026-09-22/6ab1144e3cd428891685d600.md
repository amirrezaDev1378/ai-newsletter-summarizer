## Resources & Tools

### [security-audit (GitHub Repo)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fgithub.com%2Fcloudflare%2Fsecurity-audit-skill%3Futm_source=tldrdevops/1/010001a0c3b7431a-58eb87b3-6087-4ac0-9a37-e793e6311946-000000/RBOTYe68sf7kcAUIl3OrGXCZx1sEMv2tRIHS8RtGJSI=452)
A new coding-agent skill turns an AI agent into a security auditor that orchestrates reconnaissance, vulnerability hunting, and validation. The tool runs a structured audit in six phases and classifies findings into three verdicts: confirmed, needs_validation, or rejected. Audits against the same repository are additive, using prior results to target gaps or revalidate changed source code. The skill activates automatically when an agent receives a request for a security audit or pen-test.

### [Higgsfield (GitHub Repo)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fgithub.com%2Fhiggsfield-ai%2Fhiggsfield%3Futm_source=tldrdevops/1/010001a0c3b7431a-58eb87b3-6087-4ac0-9a37-e793e6311946-000000/7bPWQjEoffhUh77TUVlDXq99xUBP9AVNmC20GSlcCfQ=452)
Higgsfield is an open-source GPU orchestration and machine learning framework designed for training models with billions to trillions of parameters. The framework aims to simplify distributed training by managing environments and reducing the need for complex configuration files. It supports standard PyTorch workflows and has been tested on AWS and Lambda Labs.

### [Saving another 100TB of RAM with math (and Rust) (11 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fblog.cloudflare.com%2Fsaving-100-tb-of-ram-with-math%2F%3Futm_source=tldrdevops/1/010001a0c3b7431a-58eb87b3-6087-4ac0-9a37-e793e6311946-000000/Qb4MpynIKCPLKlL4Bgv0m3eGgsaIFbGx4aRWBKSMMbg=452)
Cloudflare reduced the memory footprint of its Pingora Backend Router by 100TB through algorithmic optimizations to the pingora-ketama library. The team determined they could remove 90% of the hashes generated for each server without causing errors or collisions. They rolled out the change in stages to avoid invalidating cached content across the network all at once.

### [RADAR: Catch gray failures with anomaly detection (4 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fwww.databricks.com%2Fblog%2Fradar-catch-gray-failures-anomaly-detection%3Futm_source=tldrdevops/1/010001a0c3b7431a-58eb87b3-6087-4ac0-9a37-e793e6311946-000000/A1NXMvajEREfFM47fkDjlR0GRyZqfpAGLcp4Ke8Jdwo=452)
Gray failures allow specific service components to fail silently while health checks remain green, often leaking revenue for hours before detection. Databricks built a system called RADAR to catch these partial outages by identifying sudden spikes in user errors. The system reduced incident discovery time by 95% with over 90% precision. Users can build a similar detection pipeline on the Databricks platform using a template available on GitHub.
