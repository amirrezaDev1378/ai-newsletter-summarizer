# TLDR Information Security 2026-09-30

## 🔓 Attacks & Vulnerabilities

### [Pentagon Personnel Agency Data Breach Impacts 3 Million People (1 minute read)](https://links.tldrnewsletter.com/39St0p)

The Defense Manpower Data Center exposed unencrypted personal data through a vulnerable file-sharing server, with unauthorized users accessing files between October 2025 and July 16, 2026. The exposed records included Social Security numbers, names, birth dates, contact details, demographic data, and military specialties, affecting 2.76 million living people and 294,000 deceased individuals.

### [Official MCP Python SDK Flaw Can Let Malicious Servers Steal OAuth Credentials (2 minute read)](https://thehackernews.com/2026/09/official-mcp-python-sdk-flaw-can-let.html?utm_source=tldrinfosec)

A high-severity flaw in the official MCP Python SDK let malicious MCP servers redirect OAuth token requests to attacker-controlled endpoints. Affected 1.x (1.9.1–1.29.1) and 2.x (2.0.0–2.1.1) clients sent sensitive credentials to the attacker, enabling full account takeover. Fixes are available in versions 1.30.0 and 2.2.0.

### [Automated AI Agent Used to Bread Cybersecurity Nonprofit DIVD (2 minute read)](https://links.tldrnewsletter.com/ZNzvI7)

The Dutch Institute for Vulnerability Defense (DIVD) reported suffering an AI-driven breach. The organization described the attack as loud and messy due to the agent working autonomously and over-explaining itself in comments, which allowed the DIVD to easily reverse-engineer it. The threat actor exploited a vulnerability in undisclosed software.

## 🧠 Strategies & Tactics

### [Attackers Abuse ChatGPT Custom GPTs to Deliver RAT via ClickFix (15 minute read)](https://www.huntress.com/blog/chatgpt-custom-gpts-clickfix-rat?utm_source=tldrinfosec)

Sponsored Google results directed victims to a malicious Custom GPT on chatgpt.com that responded with a fake outage notice and a ClickFix lure. The multi-stage chain sideloaded malicious DLLs, hid loaders inside WAV files and NuGet packages, and unpacked a RAT utilizing DNS-over-HTTPS for C2. Defenders are advised to focus on behavioral detection like PowerShell activity spawning msiexec on GUID-named MSIs in `%TEMP%`.

### [NeedyMantis: Unpacking a post-compromise malware family used in targeted operations (14 minute read)](https://www.microsoft.com/en-us/security/blog/2026/09/28/needymantis-unpacking-a-post-compromise-malware-family-used-in-targeted-operations/?utm_source=tldrinfosec)

NeedyMantis is a modular post-compromise malware family deployed by China-based actors against telecoms, universities, and government contractors. It utilizes DLL sideloading alongside legitimate software, unpacks via shellcode loaders, and communicates over WebSockets with RC4-encrypted traffic.

### [AI Agents Are Privileged Users; Who Is Auditing Their Access? (4 minute read)](https://links.tldrnewsletter.com/ajf66N)

Enterprises often grant autonomous AI agents broad production access via long-lived service accounts, collapsing segregation of duties. This piece recommends six controls: isolate agent identities, scope permissions strictly, assign business owners, log prompts/tool calls, run periodic reviews, and build an out-of-band kill switch.

## 🧑‍💻 Launches & Tools

### [Rig Security (Product Launch)](https://www.rig.security/?utm_source=tldrinfosec)

Rig Security provides an identity protection platform for agentic AI that maps identity dependencies across providers, cloud, and on-prem environments. A lightweight sensor distinguishes AI agent sessions from human sessions to enforce runtime policies and block risky agent actions.

### [Malicious Drivers (Web App)](https://www.mahmoudzohdy.com/drivers/?utm_source=tldrinfosec)

A searchable list of tracked, signed, and abused kernel drivers.

### [cryptoptic (GitHub Repo)](https://github.com/nationwide-group-oss/cryptoptic)

Cryptoptic is a tool utilizing CodeQL and GitHub Actions to scan repositories or organizations, producing an inventory of every cryptographic function in use, its source library, and invocation points.
