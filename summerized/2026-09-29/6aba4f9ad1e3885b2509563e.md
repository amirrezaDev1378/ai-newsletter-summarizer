## Opinions & Advice

### [First Principles Thinking (4 minute read)](https://sunilsadasivan.com/writing/first-principles-thinking/?utm_source=tldrdev)
First-principles thinking asks engineers to set accumulated assumptions aside long enough to identify the real problem and the outcome that matters. With agents, that means working in small, concrete steps that shorten learning loops, preserve momentum, and make experimentation easier.

### [Plan Mode Is Dead (9 minute read)](https://www.aymannadeem.com/artificial/intelligence,/developer/tools/2026/09/24/plan-mode-is-dead.html?utm_source=tldrdev)
Plan modes turn useful thinking into long artifacts that people do not want to read and impose an artificial boundary between planning and building. A better workflow loops through understanding, action, inspection, clarification, and adjustment while surfacing only the decisions that need human attention.

### [How to Keep Enjoying Programming in a World of LLMs (8 minute read)](https://discourse.haskell.org/t/how-to-keep-enjoying-programming-in-a-world-of-llms/14705?utm_source=tldrdev)
Developers can preserve ownership, skill, and enjoyment by continuing to write the code they care about themselves. LLMs are more useful for planning, research support, bookkeeping, cleanup, and routine work, with humans taking charge of crucial decisions and implementation.

## Launches & Tools

### [Atlas (GitHub Repo)](https://github.com/pacifio/atlas?utm_source=tldrdev)
Atlas is source control for coding agents that links commits to the sessions, prompts, tool calls, and reasoning that produced them. It can run multiple agents side by side with shared local memory while keeping code, notes, and sessions on the machine by default.

### [Whiteboard (GitHub Repo)](https://github.com/devdotfast/whiteboard?utm_source=tldrdev)
Whiteboard is an open-source desktop canvas where developers and coding agents can design and review software together. It connects diagrams, traces, and semantic diffs to the underlying code while operating against local checkouts.

### [Mobile MCP (GitHub Repo)](https://github.com/mobile-next/mobile-mcp?utm_source=tldrdev)
Mobile MCP gives agents one interface for automating native iOS and Android apps across simulators, emulators, and real devices. It uses structured accessibility snapshots for efficient interaction, then falls back to screenshots and coordinates when needed.

## Miscellaneous

### [Personal AI Agents Quietly Upsell Users They Think Are Rich (6 minute read)](https://www.stacksweep.dev/ai-agents-upsell-wealthy-users?utm_source=tldrdev)
Across 325,000 trials and 13 models, agents recommended more expensive flights, insurance, and graduate programs to users they inferred were wealthy despite identical requests. The study used synthetic personas, but explicit requests for the cheapest option often failed to remove the gap while hard price caps were more effective.

### [Fifteen Years Later, the Apple Cards Origin Story (8 minute read)](https://lexontech.org/fifteen-years-later-the-apple-cards-origin-story?utm_source=tldrdev)
Apple's short-lived Cards app began as a Steve Jobs idea for sending a physical thank-you card directly from an iPhone. Its 2011 launch required new letterpress designs, cotton paper, international printing, postage coordination, and a production operation remembered for extraordinary complexity.

### [Almost Nobody Gets XML Sitemaps Right (5 minute read)](https://joost.blog/broken-sitemaps/?utm_source=tldrdev)
Sitemap Inspector began as a way to make XML sitemaps readable and evolved into a checker for redirects, HTTP errors, noindex directives, and canonical mismatches. Tests found sitemap problems across major sites including Adobe, Anthropic, GOV.UK, Manchester City, Semrush, and X.
