## 🔓 Attacks & Vulnerabilities

### [Citrix NetScaler security snafus get even worse amid more 0-day reports (3 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fwww.theregister.com%2Fsecurity%2F2026%2F10%2F05%2Fcitrix-netscaler-security-snafus-get-even-worse-amid-more-0-day-reports%2F5301232%3Futm_source=tldrinfosec/1/010001a11680083e-fbc2a963-364b-4f91-a753-2cbdbed7f008-000000/o-mqmcbt7y0O-iKN_Bo0d1KXpK9Elf_gSFrpNLzeELM=452)

A single crafted request knocks NetScaler ADC and Gateway appliances offline through CVE-2026-88779, a memory overflow zero-day affecting deployments configured as a SAML service provider or identity provider. CISA confirmed active exploitation, and watchTowr suspects attackers are crashing appliances deliberately to speed up exploitation of CVE-2026-88771. Apply Citrix's fixed build or interim mitigation and run Citrix's IOC script.

### [250,000 Impacted by Data Breaches at New Jersey, Texas Healthcare Firms (2 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Flinks.tldrnewsletter.com%2FDOsTQM/1/010001a11680083e-fbc2a963-364b-4f91-a753-2cbdbed7f008-000000/OIiHcKvDH3FHQks5bly0Iy8MEovEVTrw-bbJV-P_Xfw=452)

Clover Health Investments reported that attackers used social engineering to compromise three employee accounts, exposing data on 138,677 people. AngMar Management Services also discovered stolen patient data affecting 126,196 people. Exposed records included Social Security numbers, diagnoses, medical histories, insurance details, prescriptions, and service dates. The Interlock ransomware group claimed to have stolen 700 gigabytes from AngMar.

### [CVE-2026-19444: How copying in kubectl breaks trust (5 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Federa.dev%2Fstories%2Fcve-2026-19444-how-copying-in-kubectl-breaks-trust%3Futm_source=tldrinfosec/1/010001a11680083e-fbc2a963-364b-4f91-a753-2cbdbed7f008-000000/JhbfRIyOR7KnCmdp3DOHGvPXGZ83L5l3yUxTkl_NBb0=452)

A malicious container can write files anywhere a Windows user's account can reach, including the Startup folder, when that user runs `kubectl cp` against it (CVE-2026-19444, CVSS 6.5). The vulnerability stems from client-side extraction where entry-path checks never accounted for Windows path separators. Windows clients need to update to kubectl v1.36.5, v1.35.9, or v1.34.12.

## 🧠 Strategies & Tactics

### [WordPress libheif RCE: Exploit Chain (11 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Ffortbridge.co.uk%2Fresearch%2Fwordpress-libheif-rce%2F%3Futm_source=tldrinfosec/1/010001a11680083e-fbc2a963-364b-4f91-a753-2cbdbed7f008-000000/tXYPUX0d-wXB48IrpXFwgrrWfTEviknpU52CaB-dPso=452)

Fortbridge published the first public exploit chain for a libheif heap overflow (GHSA-x8r2-mggj-j6wr). By uploading crafted HEIC images via the WordPress Media Library, an authenticated attacker can defeat ASLR and hijack a C++ virtual table pointer to achieve remote code execution. Administrators should update libheif to 1.23.3, disable unused HEIC/AVIF uploads, and monitor for repeated PHP-FPM 503 errors on image uploads.

### [MALFEX npm Malware Campaign: Three Payloads And An Adversary That Signs Their Work (12 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fcheckmarx.com%2Fzero-post%2Fmalfex-npm-malware-campaign-three-payloads-and-an-adversary-that-signs-their-work%2F%3Futm_source=tldrinfosec/1/010001a11680083e-fbc2a963-364b-4f91-a753-2cbdbed7f008-000000/glWkDRkWdIyhdSjK94PukOxhXIwvskNqIFg5jV9NMEc=452)

MALFEX, an npm campaign by a single operator, published eight malicious packages targeting Windows systems. Payloads included Overlord RAT and movinlike, a stealer targeting Discord tokens, browser credentials, Telegram sessions, and cryptocurrency wallets. Three packages (`function-flag`, `function-color`, and `cdn-img-fetch`) remain installable.

### [A Vault with a Heap-View: The Uncomfortable Space Between AgentCore Harness and Identity (16 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Funit42.paloaltonetworks.com%2Fsecuring-aws-agentcore-harness-credentials%2F%3Futm_source=tldrinfosec/1/010001a11680083e-fbc2a963-364b-4f91-a753-2cbdbed7f008-000000/BSrf6rkvC6HlPD0CdolaM_oTq32ig78wsQKBKJoy8gs=452)

Unit 42 discovered that the bash tool enabled by default on AWS AgentCore agents runs arbitrary commands and code as root. Researchers utilized this primitive to exfiltrate the AgentCore Identity JWT by scanning the heap.
