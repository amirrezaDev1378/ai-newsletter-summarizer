### [OpenCode Security Breach Exposes API Keys of 1.4% of Console Users (3 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fblockonomi.com%2Fopencode-security-breach-exposes-api-keys-of-1-4-of-console-users%2F%3Futm_source=tldrinfosec/1/010001a154539b81-f4bd59da-c0ee-4179-99b4-413637975734-000000/hNE75dxeC7Qk4PTcwAHFS8RxNlerB9yP4QEB35CVO7g=452)

The breach occurred as part of a distillation attack on a legacy system. Affected customers have been contacted and are being instructed to revoke the exposed keys.

### [Fake Claude, ChatGPT Attacks Surge, Putting Developers at Risk (3 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Flinks.tldrnewsletter.com%2FUDLbmi/1/010001a154539b81-f4bd59da-c0ee-4179-99b4-413637975734-000000/rm9V8xgpsuXTQx-B1ZXoK-EkpmpGlQ3UcqOJlYrwdc4=452)

Attackers impersonated Claude in 60% of cases and ChatGPT or Codex in 33%, using malicious ads, SEO poisoning, fake download pages, shared chats, and artifacts. ClickFix-style commands appeared in 45% of cases. Targets risk losing source code, SSH keys, CI/CD tokens, cloud and AI API keys, sessions, and billing access.

### [Frozen Privilege: Remote Code Execution in Snowflake-Managed PostgreSQL (10 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fwww.varonis.com%2Fblog%2Fremote-code-execution-in-snowflake-managed-postgresql%3Futm_source=tldrinfosec/1/010001a154539b81-f4bd59da-c0ee-4179-99b4-413637975734-000000/thPUjiiFHpRZHKKQ0-Zu_IJJKYnX33MEyH32K5NM_6A=452)
Varonis researchers found that Snowflake-managed PostgreSQL's non-superuser snowflake_admin role could be escalated to OS-level RCE by chaining five documented PostgreSQL features, defeating every published mitigation without disabling any. The chain used CREATEROLE to self-grant pg_write_all_data and hijacked a pg_cron job to run as postgres. It then rebound blocked functions through LANGUAGE internal, exposing tenant mTLS keys and AWS STS credentials and allowing an overwrite of archive_command. Snowflake has fixed the issue server-side, but teams running their own PostgreSQL should treat CREATEROLE as near-superuser, block LANGUAGE internal and C function creation, and audit pg_cron jobs and SECURITY DEFINER functions.

## 🧠 Strategies & Tactics

### [Exposing AdFection: How Discover-Tech Turned Targeted Ads Into a Pipeline for Zero-Click Mercenary Spyware (30 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fcitizenlab.ca%2Fresearch%2Fhow-discover-tech-turned-targeted-ads-into-a-pipeline-for-spyware%2F%3Futm_source=tldrinfosec/1/010001a154539b81-f4bd59da-c0ee-4179-99b4-413637975734-000000/pNDFd4xmv7NFIPDE0ziIemPnvI22B9z0ooo1vQujG1Q=452)
Citizen Lab links Israeli ad company Discover-Tech to zero-click delivery of Candiru spyware through targeted advertisements. Its Controlium platform lets customers select targets by mobile ad ID, cookie ID, or IP address, then run JavaScript when an ad is rendered. At least 45 Al Jazeera devices were infected in 2024 and 2025. Nearly four billion bidding records show ads across almost 200,000 sites and apps. Google, IAB Europe, Beeswax, Vungle, and Eskimi cut Discover-Tech's access after disclosure. A separate actor, DARK CARTOGRAPHER, used the infrastructure to link advertising IDs with phone numbers.

### [Big Fish: Exploiting a 37-Year-Old Kernel Bug in OpenBSD (4 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fcalif.io%2Fresearch%2Fbig-fish%3Futm_source=tldrinfosec/1/010001a154539b81-f4bd59da-c0ee-4179-99b4-413637975734-000000/PWhDj80feZ727UD9X1swNQvNMWTZFtfuV77HmrCZAJ0=452)
Calif reported two OpenBSD vulnerabilities that enabled local privilege escalation to root. A signed 16-bit shared-memory attachment counter, dating to the original BSD sources, could overflow after repeated forking and wrap to a negative value. That enabled a use-after-free race condition. A separate out-of-bounds write gave the exploit a write-what-where primitive. The exploit worked with KARL, SMAP, and SMEP enabled, using heap grooming, SysV shared-memory manipulation, IP multicast socket allocations, and PTE self-referential mapping changes to reach kernel execution.

### [Heartbreaker: Metamorphic ransomware comes for macOS (13 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fobjective-see.org%2Fblog%2Fblog_0x8A.html%3Futm_source=tldrinfosec/1/010001a154539b81-f4bd59da-c0ee-4179-99b4-413637975734-000000/6RP6_dGW5vk-cqhpCekcr_cXPs_yC93v6qzqn9wUebo=452)
Heartbreaker, a previously undetected Rust ransomware for Apple Silicon Macs, encrypts files in ~/Downloads with AES-256-GCM, persists through a LaunchAgent, and then rebuilds itself by mutating its own embedded source code and recompiling with Cargo to change its hash each run. Patrick Wardle found the rebuild fragile and noisy because it may install Rust on the fly, depends on a now-deleted GitHub framework, and uses a single hard-coded key that lets victims decrypt every file for free. His open-source RansomWhere? tool still caught it by flagging an untrusted process that rapidly writes high-entropy files, which shows why behavior-based detection holds up against mutating binaries better than hash-based signatures.

## 🧑‍💻 Launches & Tools

### [CVE Intel (GitHub Repo)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fgithub.com%2FFazmin%2Fcve-intel%3Futm_source=tldrinfosec/1/010001a154539b81-f4bd59da-c0ee-4179-99b4-413637975734-000000/ipUpPHwpLotylnryF6G9tTndGjp79wbUNkXPW5z1wvw=452)
CVE Intel is a Rust-based triage tool that queries 25 sources, including NVD, EPSS, CISA KEV, and Shodan, in parallel and returns a single 0 to 100 patch-priority score for a CVE, IP, hash, domain, or dependency list. It runs as a Tauri desktop app, CLI, REST API, or MCP server, and its built-in llama.cpp model explains findings locally by default. Teams can also integrate it into CI to fail builds on vulnerable dependencies or rank scanner output using real exploitation signals rather than CVSS alone.

### [The PQC Migration Budget Builder Turns Deadlines and Estate Counts Into a Defensible Budget Request (18 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fpostquantum.com%2Fpqc-governance%2Fpqc-budget-builder-guide%2F%3Futm_source=tldrinfosec/1/010001a154539b81-f4bd59da-c0ee-4179-99b4-413637975734-000000/6yHDFJfUe0kDZZKrbYTdYgp0AM6MlqDqQolL53NiI_k=452)
The PQC Migration Budget Builder is a free, browser-only tool that converts regulatory deadlines and rough estate counts into an itemized year-one ask, a three-scenario program estimate, and a draft board paper for post-quantum migration. It maps 33 regimes, including the EU roadmap, OMB M-26-15, DORA, and PCI DSS v4.0.1, to buffered priority and full-migration dates, then prices compression, refresh-funded savings, and the cost of delaying migration by one to three years. Each unit cost is labeled by source and editable, allowing CISOs and finance partners to stress-test the numbers before discovery replaces the estimates.

### [SSHamble (GitHub Repo)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fgithub.com%2FrunZeroInc%2Fsshamble%3Futm_source=tldrinfosec/1/010001a154539b81-f4bd59da-c0ee-4179-99b4-413637975734-000000/8FdJSXCFCdAARt8cgmUfaCl5XrgG5EyLD0goX0tdeIU=452)
SSHamble is a tool for testing SSH implementations that includes: interesting attacks against authentication, post-session authentication attacks, pre-authentication state transitions, authentication timing analysis, and post-session enumeration.

### [Calendar Invite Phishing Can Leave Malicious Events on Your Calendar (6 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Ffirethering.com%2Fcalendar-invite-phishing-attacks%2F%3Futm_source=tldrinfosec/1/010001a154539b81-f4bd59da-c0ee-4179-99b4-413637975734-000000/SkGgO0-EnZYz608uEbUKLGPINWgGrkZm_xjynUOIhT4=452)
Phishing links, QR codes, and fake payment notices delivered via malicious .ics invites can remain on a victim's calendar even after email security tools quarantine the original message, because many filters fail to remove the events those emails auto-created. Sublime Security documented this gap in Google Workspace and Microsoft 365 and projected a roughly 33,000% increase in calendar-based attacks from May to September. Check Point separately flagged more than 302,000 unique phishing emails across 40,000+ organizations in a calendar-themed Microsoft 365 campaign.
