## News & Trends

### [Introducing Scout 1.0: A new SRE model powering Bits AI with frontier performance at a fraction of the cost (4 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fwww.datadoghq.com%2Fblog%2Fai%2Fintroducing-scout-sre-specialized-model-bits-ai%2F%3Futm_source=tldrdevops/1/010001a153e8fc27-5cdca64a-a4cd-4bb3-b193-bd092f002bea-000000/VAwg5MEM6aR4dVjqKHAKVbYKEJ41rsYl_Uk3gJha-cY=452)
Datadog's Scout 1.0 is an AI model specialized for investigating production issues that powers its Bits AI assistant. The model matches the performance of general-purpose frontier models like GPT-6.1 Sol and Claude Opus 5.5 at three to eight times lower estimated inference cost. Datadog trained Scout using reinforcement learning on simulations built from historical incidents.

### [Claude Platform Tracing in New Relic (4 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fnewrelic.com%2Fblog%2Fnews%2Fanthropic-otel-ai-observability%3Futm_source=tldrdevops/1/010001a153e8fc27-5cdca64a-a4cd-4bb3-b193-bd092f002bea-000000/gAiFjQG16S70BG6I3eVWtEl51XpjOqUvBRprnA3dklk=452)
The Claude Platform now exports OpenTelemetry traces natively from Claude Managed Agents, the Messages API, and the Claude SDKs in public beta. New Relic AI Monitoring reads these traces to link model performance with application data in a single view. Users can add New Relic as a destination in the Claude Console to start receiving spans within about a minute without code changes.

### [Cloudflare and OpenAI: making AI discovery better for everyone (5 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fblog.cloudflare.com%2Fcloudflare-openai-discovery-agentic-web%2F%3Futm_source=tldrdevops/1/010001a153e8fc27-5cdca64a-a4cd-4bb3-b193-bd092f002bea-000000/ywB-BezzCqG1yNNAYpv2IMU4XZLaaOjstavaQoFKPwY=452)
A research pilot between Cloudflare and OpenAI has enabled the discovery and indexing of hundreds of millions of new web pages. The program used signals from roughly 1% of Cloudflare's network to help ChatGPT find content that was previously unknown. These signals identify useful pages and filter out nonexistent or duplicated content, which reduces unnecessary crawling load for site owners. Cloudflare states the metadata is used for search discovery rather than training AI models.

### [Agent-first IDP: how big tech and the clouds are preparing platforms for agents (22 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fplatformengineering.org%2Fblog%2Fagent-first-idp-how-big-tech-and-the-clouds-are-preparing-platforms-for-agents%3Futm_source=tldrdevops/1/010001a153e8fc27-5cdca64a-a4cd-4bb3-b193-bd092f002bea-000000/hCziYjItqc0wqqrg-jP3cv8_-YUcxCjIOcaOFYIQ-4Y=452)

### [Finding (and Fixing) a Silent Throughput Ceiling in PostgreSQL (6 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fwww.enterprisedb.com%2Fblog%2Ffinding-and-fixing-silent-throughput-ceiling-postgresql%3Futm_source=tldrdevops/1/010001a153e8fc27-5cdca64a-a4cd-4bb3-b193-bd092f002bea-000000/7BLcKkHIUzQPb-iMnt4V2hiDlIh6WSx3yHVxcVWEvGk=452)
PostgreSQL throughput can stall under heavy concurrent inserts even when CPU and storage have spare capacity, as writers queue behind relation extension locks. In a HammerDB benchmark, distributing writes across hash partitions reduced contention and increased throughput 7.2× on the same hardware.
