# TLDR Information Security 2026-09-09

## Attacks & Vulnerabilities

### [WeWorm (4 minute read)](https://calif.io/research/weworm?utm_source=tldrinfosec)
Calif demonstrated a zero-click worm that compromises WeChat accounts via unanswered VoIP calls. The exploit uses a memory corruption bug in the VoIP stack. While it requires the attacker to be on the victim's friend list, a single compromised contact can facilitate a chain reaction. Tencent has released server-side mitigations and client updates (Android 8.0.77 / iOS 8.0.76).

### [220M Traveler Records Exposed in Vietnam-Linked APIS Leak (2 minute read)](https://links.tldrnewsletter.com/NEF1Xc)
Researchers accessed an Elasticsearch cluster containing Advanced Passenger Information System (APIS) data for 220 million passengers and crew. The database was accessible via a cloud-based path using default credentials. Exposed data includes names, dates of birth, nationalities, and passport numbers.

### [Hackers Breach F5 BIG-IP APM Devices to Deploy Linux Rootkit (2 minute read)](https://links.tldrnewsletter.com/IvoITh)
A malware campaign labeled "PoisonedRefresh" is targeting F5 BIG-IP APM devices. Attackers exploit a critical RCE vulnerability to inject a fileless web shell, infect the Apache executable, and modify SELinux configurations to deploy a rootkit.

## Strategies & Tactics

### [Hacking AI customer service agents (11 minute read)](https://www.intigriti.com/researchers/blog/hacking-tools/hacking-ai-customer-service-agents?utm_source=tldrinfosec)
Security researchers demonstrated how AI support agents can be manipulated via email spoofing, duplicate headers, and parser mismatches. These techniques can trigger unauthorized refunds, account data disclosure, or knowledge base poisoning through hidden CSS text and sitemap manipulation.

### [RFD 301: Has anybody seen my keys?: A key-hierarchy strategy for rack-level security (12 minute read)](https://rfd.shared.oxide.computer/rfd/0301?utm_source=tldrinfosec)
Oxide detailed its design for rack-level data-at-rest protection. The system uses a Shamir-shared rack secret to derive per-drive ZFS wrapper keys. The strategy focuses on ensuring that compromising a single disk does not expose others and utilizes a two-phase commit process for rotating secrets.

### [The Shared Clipboard Inside the Sandbox: Cross-Account Data Leakage in ChatGPT (10 minute read)](https://research.checkpoint.com/2026/the-shared-clipboard-inside-the-sandbox-cross-account-data-leakage-in-chatgpt/?utm_source=tldrinfosec)
Check Point Research found that ChatGPT code-execution containers could communicate across accounts via shared JFrog Artifactory metadata. This allowed a hidden task stream to exfiltrate data from a victim's connected services (like Gmail) while providing a clean visible response. OpenAI has since decommissioned the vulnerable instance.

## Launches & Tools

### [Prism-platform (GitHub Repo)](https://github.com/NovaCode37/Prism-platform?utm_source=tldrinfosec)
An all-in-one OSINT platform featuring 22+ modules, AI analysis, real-time dashboards, and OPSEC scoring for scanning domains, IPs, and usernames.

### [Sage (GitHub Repo)](https://github.com/gendigitalinc/sage?utm_source=tldrinfosec)
A security tool designed to intercept and block dangerous tool calls made by AI coding assistants. It uses URL reputation checks, local heuristics for risky commands, and ML-based prompt injection detection.

### [DecBench (Website)](https://decbench.com/?utm_source=tldrinfosec)
A benchmark from Noelo Lab that evaluates the performance of decompilers and LLMs on exact source code recovery, measuring metrics like control flow structure and recompilability.

## Miscellaneous

### [Fake IT Calls Target Executives in Microsoft 365 Data Theft and Extortion Attacks (2 minute read)](https://thehackernews.com/2026/09/microsoft-365-attackers-use-help-desk.html?utm_source=tldrinfosec)
The threat group PREY-0058 uses social engineering (fake IT calls) and Adversary-in-the-Middle (AitM) pages to bypass MFA and steal Microsoft 365 session tokens. They then exfiltrate data from SharePoint and OneDrive for extortion.

The UK National Audit Office has flagged cyberattacks as a major risk to the food supply chain. Recent incidents involving Marks & Spencer and Co-op highlight the significant financial and data costs of these breaches.
