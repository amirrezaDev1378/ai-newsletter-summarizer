## News & Trends

### [Scale your AI workloads faster and more efficiently with GKE Pod snapshots (4 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fcloud.google.com%2Fblog%2Fproducts%2Fcontainers-kubernetes%2Fgke-pod-snapshots%2F%3Futm_source=tldrdevops/1/010001a0d85118d4-d2b0ac5b-138f-4836-9609-b7ef7515bfc3-000000/H0RuIp_VWbepT-tsXnwBt9Qk29HAGQpTW5BPcj-QxHk=452)

Google Kubernetes Engine has added Pod snapshots, which capture a workload's running CPU and GPU memory state to restore it on demand. This cuts AI inference startup times by up to 89 percent—loading a 70B parameter model in 37 seconds. Codeway's Retake successfully reduced startup time to eight seconds using this feature.

### [Cloudflare Introduces the Agent Development Stack Lifecycle to Replace Traditional SDLC (2 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fwww.infoq.com%2Fnews%2F2026%2F09%2Fcloudflare-adlc-agents%2F%3Futm_source=tldrdevops/1/010001a0d85118d4-d2b0ac5b-138f-4836-9609-b7ef7515bfc3-000000/tOrVsCZmes6W0Bt_mfdlvFxxQQEecc-hEcURm6aVwKY=452)

Cloudflare has introduced an Agent Development Lifecycle designed to replace traditional software pipelines with autonomous, event-driven systems for AI coding agents. Built on its Workflows product and a new `@cloudflare/ci` tool, it incorporates OpenTelemetry-based observability and an Agent Access Model that issues short-lived, capability-limited credentials to prevent lateral movement.

### [Better prompt caching for GPT-6 (3 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Flinks.tldrnewsletter.com%2F0F2FWy/1/010001a0d85118d4-d2b0ac5b-138f-4836-9609-b7ef7515bfc3-000000/SVekFnloeDS8_TO2_rNKO_1Z3Dh8Im3yWRjDYl1UQ_s=452)

OpenAI has launched an improved prompt caching system for the GPT-6 family, delivering higher cache hit rates by default. Developers can receive discounts of up to 90% on cached input tokens when reusing shared prefixes within a 30-minute window. New tools include a Prompt Caching Dashboard to track hit rates and a diagnostics tool for investigating unexpected misses. Developers can also prewarm the cache to reduce latency or adjust reasoning effort between responses without breaking the cache.

The specialized student model achieved 87% of the teacher's recall while reducing inference costs roughly 20-fold to $0.003 per investigation. A single 40 GB A100 GPU can support approximately 100,000 of these investigations per week.

The toolkit supports tools, structured output, and model providers like Amazon Bedrock, Anthropic, and OpenAI.

## Miscellaneous

### [Global AI routing with <1% overhead on multi-cluster GKE Inference Gateway (6 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fcloud.google.com%2Fblog%2Fproducts%2Fcontainers-kubernetes%2Fgpu-and-tpu-utilization-with-multi-cluster-gke-inference-gateway%2F%3Futm_source=tldrdevops/1/010001a0d85118d4-d2b0ac5b-138f-4836-9609-b7ef7515bfc3-000000/c8Oqfj19TZCdc80C7crvN3cgSk3008PdmdaVJvp8EHM=452)

Google's multi-cluster GKE Inference Gateway pools globally distributed accelerator capacity behind a single endpoint, routing LLM traffic based on live KV-cache utilization instead of round-robin algorithms. A 17,000-node benchmark across three regions demonstrated near-linear throughput scaling with less than 1 percent routing overhead and a 99.9 percent success rate.

### [Docker Sandbox Kit Spec: Authority as Code (7 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fwww.docker.com%2Fblog%2Fdocker-sandbox-kit-spec%2F%3Futm_source=tldrdevops/1/010001a0d85118d4-d2b0ac5b-138f-4836-9609-b7ef7515bfc3-000000/pdDwJo__RhdQSYLGEfdwX5iwVEquLWlYo5Tlb5gglnM=452)

The Docker Sandbox Kit Specification v3 defines how to package an agent's permissions and dependencies into a standard OCI image. The format details network rules, credentials, and volumes, enabling developer tooling to scan, sign, and diff changes to agent authority. Docker Sandboxes is the first runtime to conform to this open-source specification.
