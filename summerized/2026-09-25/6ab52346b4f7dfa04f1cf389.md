## 🔓 Attacks & Vulnerabilities

### [Critical Bifrost AI Gateway Flaw Lets Attackers Run Commands Without Credentials (3 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fthehackernews.com%2F2026%2F09%2Fcritical-bifrost-ai-gateway-flaw-lets.html%3Futm_source=tldrinfosec/1/010001a0d391bad9-24e393bb-dc2c-42b8-9904-1f5ab2072387-000000/geL_mRa9qcrjE12s736jQRSJ0JwU_yvGx2J_cuskyLY=452)
Bifrost, an open-source AI gateway for 20+ LLM providers, ships with management auth disabled by default, allowing a single unauthenticated POST request to `/api/mcp/client` to register a stdio MCP client and run arbitrary commands as the gateway user (CVE-2026-90898, CVSS 9.8). This exposes stored provider API keys. Users should upgrade to transports/v2.1.0 or enable `governance.auth_config.is_enabled`.

### [BigCommerce Data Stolen via Ribon Apps Hack (2 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Flinks.tldrnewsletter.com%2FLp1K2G/1/010001a0d391bad9-24e393bb-dc2c-42b8-9904-1f5ab2072387-000000/39biWIvwffYl7Z4T3MTLNhrKxwOhXTjyXSLO5daL4cw=452)
Attackers utilized compromised Ribon API credentials from a Fastr system breach to access BigCommerce merchant customer data, exposing names, email addresses, phone numbers, and postal addresses. BigCommerce has since revoked the credentials and uninstalled affected Ribon apps.

### [GitHub App Private Keys: 474 Leaked Keys Exposed (11 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fblog.gitguardian.com%2Fgithub-app-private-keys-leaked%2F%3Futm_source=tldrinfosec/1/010001a0d391bad9-24e393bb-dc2c-42b8-9904-1f5ab2072387-000000/RXlbRq1hMoYDNyAx2Q-1KQ8xaCSQw3-UPHSH5JauL2o=452)
GitGuardian tested 4,802 leaked GitHub App private keys and found 474 still actively authenticated across 440 apps. Since these keys have no expiration date, the leaked PEM files remain usable indefinitely.

## 🧠 Strategies & Tactics

### [The Tale of Two INC Ransom Notes (8 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fwww.huntress.com%2Fblog%2Ftwo-inc-ransom-notes%3Futm_source=tldrinfosec/1/010001a0d391bad9-24e393bb-dc2c-42b8-9904-1f5ab2072387-000000/R2r1CRGT2sTOhVmHXg3CowO4-LDz6dYbZZREo7iSJj8=452)
An INC ransomware intrusion across multiple endpoints began with randomly named scheduled tasks launching an obfuscated PowerShell implant, followed by a quiet period before utilizing AnyDesk, a BYOVD EDR killer, and Impacket's `atexec.py` to deploy the payload. Defenders should monitor for unexpected RMM installations, unsigned driver services, and unauthorized scheduled tasks.

### [Revoking the token didn't kill the backdoor (6 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fwww.csoonline.com%2Farticle%2F4223975%2Frevoking-the-token-didnt-kill-the-backdoor.html%3Futm_source=tldrinfosec/1/010001a0d391bad9-24e393bb-dc2c-42b8-9904-1f5ab2072387-000000/twVA1hifE5dIXXsCR1umFw3Wd4-RPoem2sqXlYoFTgI=452)
GraphWorm, an implant linked to the China-nexus group Webworm, leverages a legitimate OneDrive account as a dead drop. Its upgrade task swaps out hardcoded OAuth credentials for a backup account, rendering basic token revocation insufficient. Mitigation requires simultaneous host isolation or app ID blocking, alongside log analysis.

### [Handle Redirect (17 minute read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Flinks.tldrnewsletter.com%2FxMXmyI/1/010001a0d391bad9-24e393bb-dc2c-42b8-9904-1f5ab2072387-000000/yQG7pONSsFrhaIqtQ09gpfR07bqmbs5EzC4Lul-agss=452)
This article demonstrates a technique where an attacker bypasses EDR callbacks by calling `OpenProcess` on a benign process (like `notepad.exe`) and redirecting the resulting handle to a sensitive process like `lsass`. Kernel-level security products can detect this by periodically auditing process handle tables.
