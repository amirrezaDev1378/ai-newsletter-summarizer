# TLDR Information Security 2026-09-09

## 🔓 Attacks & Vulnerabilities

### [WeWorm (4 minute read)](https://calif.io/research/weworm?utm_source=tldrinfosec)
Calif has demonstrated a zero-click worm that takes over a WeChat account via an unanswered VoIP call, subsequently using that account to call the victim's contacts. The exploit targets a memory corruption bug in WeChat's VoIP stack. While it requires the attacker to be on the victim's friend list, a single compromised account can spread the worm through the network. Tencent has released server-side updates and client-side patches (Android 8.0.77 and iOS 8.0.76).

### [220M Traveler Records Exposed in Vietnam-Linked APIS Leak (2 minute read)](https://links.tldrnewsletter.com/NEF1Xc)
Security researchers accessed an Elasticsearch cluster containing an Advanced Passenger Information System (APIS) database with records for 220 million passengers and flight crew members. The database was accessible via default credentials through a cloud-based path. Exposed data includes names, dates of birth, nationalities, and passport numbers.

### [Hackers Breach F5 BIG-IP APM Devices to Deploy Linux Rootkit (2 minute read)](https://links.tldrnewsletter.com/IvoITh)
A malware campaign is targeting F5 BIG-IP APM devices by exploiting a critical RCE vulnerability. Attackers are injecting fileless web shells and a payload identified as "PoisonedRefresh," which infects the Apache executable and modifies SELinux configurations.

## 🧠 Strategies & Tactics

### [Hacking AI customer service agents (11 minute read)](https://www.intigriti.com/researchers/blog/hacking-tools/hacking-ai-customer-service-agents?utm_source=tldrinfosec)
Researchers demonstrated various attacks against AI-driven customer support agents using email spoofing, parser mismatches, and hidden instructions in MIME parts or CSS. These vulnerabilities can lead to unauthorized profile changes, fraudulent refunds, and account data disclosure.

### [RFD 301: A key-hierarchy strategy for rack-level security (12 minute read)](https://rfd.shared.oxide.computer/rfd/0301?utm_source=tldrinfosec)
Oxide has detailed its internal design for protecting rack data at rest. The system uses a Shamir-shared rack secret to ensure that an attacker cannot recover data without physically stealing a threshold number of drives. It utilizes HKDF with SHA3-256 for deriving per-drive keys and implements a two-phase commit for secret rotation.

### [The Shared Clipboard Inside the Sandbox: Cross-Account Data Leakage in ChatGPT (10 minute read)](https://research.checkpoint.com/2026/the-shared-clipboard-inside-the-sandbox-cross-account-data-leakage-in-chatgpt/?utm_source=tldrinfosec)
Check Point Research found that ChatGPT code-execution containers were using package metadata on a shared internal Artifactory instance as a covert communication channel. This allowed for potential cross-account data leakage. OpenAI has since decommissioned the affected instance.

## 🧑‍💻 Launches & Tools

### [Prism-platform (GitHub Repo)](https://github.com/NovaCode37/Prism-platform?utm_source=tldrinfosec)
An all-in-one OSINT platform featuring over 22 modules, AI-driven analysis, real-time dashboards, and OPSEC scoring for scanning domains, IPs, and identities.

### [Sage (GitHub Repo)](https://github.com/gendigitalinc/sage?utm_source=tldrinfosec)
A security tool designed to intercept and block dangerous tool calls made by AI coding assistants. It includes URL reputation checks, 300+ local heuristics for command safety, and ML-based prompt injection detection.

### [DecBench (Website)](https://decbench.com/?utm_source=tldrinfosec)
A benchmark platform from the University of Georgia that scores decompilers and Large Language Models (LLMs) on their ability to accurately recover source code and maintain control flow structure.
